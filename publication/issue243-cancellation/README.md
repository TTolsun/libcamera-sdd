# 요청 취소의 내부 플래그와 완료 상태

공개 PR #98이 기존 네 미판정을 해결했고 PR #99가 그 수정을 공식 소스 c19d051에 반영했습니다. 이 후속 검토는 최신 공개 원고에서 내부 취소 플래그 설정과 이후 요청 상태 대입을 한 시점처럼 읽히게 한 별도 문제를 확인했습니다.

Codex CLI gpt-6.1-terra high로 취소 답변 하나를 보정했습니다. 내부 취소는 대기 버퍼 알림을 보낸 뒤 `cancelled_`를 설정합니다. 이어 `completeRequest`가 호출하는 `Request::Private::complete()`에서 요청 상태를 `RequestCancelled`로 바꿉니다. 일반 완료 그림은 모든 버퍼 완료와 필요한 후속 작업 조건을 유지하며 적용 범위를 명시합니다. 기존 그림 주소도 보존했습니다.

별도 지정 CLI가 네 원래 지적과 변경된 한영 원고 및 그림을 대조했습니다. 표준 계약 감사, 원래 실패 기록, 검증한 원본 영수증과 실행 범위는 `resolution.json`과 증거 archive에 있습니다. 사람 검토는 대기 상태입니다.

예제 설정의 보정과 CI는 [생성기 PR #291](https://github.com/TTolsun/camera-hal-sdd-generator/pull/291)에 기록했습니다. 공개 사이트 조립은 직전 발행과 동일한 고정 생성기 버전으로 수행했습니다. 이 패키지는 배포 전 후보를 기록합니다.
