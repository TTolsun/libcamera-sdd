# 공개 요청 계약 네 건의 근거와 검증

공개 SDD PR #97의 자동 미판정 네 건을 보완했습니다. 분석 기준은 `be7e83e91348250c015aad6d6f59f1468555bae8`입니다. 공식 upstream과 공개 미러의 `c19d05128f3ae1f0ebe63acb4deaca9fbb1dde78`에서도 이번 계약에 사용한 네 소스 파일은 바이트가 같습니다. 새 IPA·장치 파이프라인 변경 19개는 별도 분석 범위입니다. 기존 공개 추출을 사용했습니다.

| 원래 판정 | 확인한 근거 | 변경 |
|---|---|---|
| `catalog/9d141e4b7ca20344` 및 `/en`의 모호함 | `Camera::queueRequest()`에서 접근·생성 카메라·상태·controls 검사 뒤에 빈 버퍼·활성 스트림 검사가 있습니다. | 각 분기에 도달하는 조건과 반환값을 한영으로 표시했습니다. `0` 반환과 별도의 요청 완료 신호도 구분합니다. |
| `catalog/948d857e662479be/en`의 근거 부족 | `CameraConfiguration::validate()`의 Adjusted와 호출자 의무, `Camera::configure()`의 Valid 비교와 `-EINVAL` 반환을 대조했습니다. | 관찰·기록을 미실시 실행 확인 항목으로 분리했습니다. 코드 사실과 조사 계획의 표시 및 메타데이터를 맞췄습니다. |
| `pipeline-requests.md/completion/6`의 모호함 | 일반 완료 API와 CameraManager 스레드 의무, `PipelineHandler::cancelRequest()`, `Request::Private::cancel()`과 `doCancelRequest()`를 대조했습니다. | 일반 완료와 내부 대기 버퍼 취소·알림을 구분했습니다. 그림 간선에는 모든 버퍼 완료, 필요한 경우의 후속 처리, 명시적 `completeRequest()`를 표시했습니다. |

아홉 선택 단위와 취소 상세 한 단위를 지정 Codex CLI / `gpt-6.1-terra` / high로 검토하고 실제 영수증에 연결했습니다. 변경한 원고는 Camera Requests, Pipeline Requests, Request Diagnosis 세 페이지입니다. 이 세 원고에서 선택 범위 밖 답변 50개와 순서를 검증했습니다. 기존 설정 기반 그림의 한 간선을 보완했고 그 한영 Mermaid 두 파일의 변경을 확인했습니다. `resolution.json`은 원래 네 판정에 대응하는 현재 주장·근거·판정과 소스 위치를 기록합니다.

처음 전체 감사에서는 새 24배치와 기존 65배치를 처리했습니다. 취소 구현 창을 추가한 뒤 새 6배치와 기존 83배치를 처리했습니다. 그림 보완을 포함한 최종 감사에서 현재 입력의 89배치를 재검증했습니다. 모순과 미판정은 각각 0건입니다. 변경된 최종 한영 표시 12쌍은 독립 CLI로 대조했습니다. 자동 판정의 범위와 한계는 계약 보고서에 있습니다.

실행 중 저장·설정 오류와 CLI 사용 한도, 의미 중복으로 중단된 시도가 있었습니다. 검토 패킷에 섞인 이전 질문 설정도 실제 발행 입력으로 교체해 다시 대조했습니다. 원본 요청·응답·stdout·영수증, 실패 로그와 양쪽 검토를 함께 보관합니다. 원본 CLI 호출, 현재 재검증, 임시 조립은 각각 실행 기록에 표시됩니다. `native-verification.json`의 신규 완료 수에는 사용하지 않은 중간 응답도 포함됩니다.

최종 빌드 `a2ce058e3adeea00f10a11ede1b2f6276283ecad3ff94b2a170d4658e8535700`에서 작성 맥락 없이 파트원과 기술 의사결정자 역할을 대리한 서브에이전트가 과업을 수행했습니다. `evaluation-*.json`에 실제 읽은 경로와 답변, 남은 읽기 부담을 보관합니다. 공개 소스의 기술 계약과 실제 대상의 관찰 계획을 구분했습니다. 파트원 평가에서는 기존 구성 진단의 Fatal 뒤 `-EINVAL` 코드 위치를 실제 반환으로 오해할 여지가 남았습니다. 의사결정자 평가에서는 여러 그림 근거 링크가 긴 발췌의 같은 시작점으로 연결되어 발췌 안에서 다시 찾는 부담이 있었습니다. 실제 사람·임원 평가와 사내 HAL 적용은 미검증입니다. 새 장치 실행 결과와 개발 기간·ROI는 미측정입니다.

반복 정상 export는 동일하며 66페이지, 내부 링크 오류 0건입니다. 한영 데스크톱·모바일에서 변경 페이지와 역할별 직접 탐색, 그림 확대·검색을 검증했습니다. 최종 Pages 실행과 실제 공개 파일 확인은 이 패키지의 공개 PR에 기록합니다.

재현에는 [고정된 #253 공개 입력과 원본 기록](../issue253-reader-followup/README.md), 이 패키지의 변경 입력·소스 커밋·생성기 버전이 필요합니다. 원래 로컬 경로는 복원 환경에 맞춰 연결합니다. `archive-index.json`과 `package.json`에서 파일 및 archive 해시를 확인할 수 있습니다. 이번 변경의 질문별 그림 검토는 `per-item-contracts.json`에 있습니다. 이 짧은 근거 비교는 표와 원본 참조로 충분하여 별도 장식 그림을 생략했습니다.

생성기 PR #286은 `29317f421da5b4b5674bccee54b4121127505731`로 병합됐습니다. 동시 반영된 #284와 #287의 검사 정책을 적용해 계약 그룹별로 실제 독립 CLI 검토를 수행했습니다. 병합 정책의 최종 표준 감사에서 89개 배치를 확인했습니다. 최종 전체 실행의 새 호출은 0개이며, 원본 영수증을 재검증한 배치는 89개입니다. 현재 보고서의 자동 미판정은 0건입니다. 병합 전 평가와 병합 후 평가, 각 그룹의 원본 실행 및 최종 실행 장부를 보관합니다.
