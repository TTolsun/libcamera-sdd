# #162·#163 통제 시험의 원본 증거

공개 libcamera `e117198c015057761bb0bbaa85f963c41ce412d7`의 독립 신규 생성과 별도 중단·복구 시험입니다. 최신 소스의 전체 원고·번역·배포 증거와는 구분합니다. 사내 HAL·실기기 검증과 실제 사람 독자 평가 결과는 없습니다.

`controlled-trials.zip`은 9,404개 논리 파일을 SHA-256으로 식별한 4,807개 고유 blob과 경로 색인으로 보존합니다. 파일 크기는 11,010,091바이트, SHA-256은 `e76a7d617a0ac85962461275a2b0513ae6e20ac4f2f23c11393e48aff35f527c`입니다. `SHA256.json`과 대조하세요. 같은 내용을 여러 번 담는 대신 `index.json`에서 원래 경로와 blob을 연결했으며 요청·응답·완료 영수증·native stdout은 원래 바이트를 유지합니다.

```powershell
python restore_controlled_evidence.py controlled-trials.zip
python restore_controlled_evidence.py controlled-trials.zip --out restored --prefix after-grouped-v5/
```

첫 명령은 모든 blob의 해시·길이·경로를 검사합니다. 두 번째는 새 디렉터리에 선택한 원본 바이트를 복원합니다. 기존 디렉터리를 덮어쓰지 않습니다. 복원은 모델을 호출하지 않으며 신규 생성 성공의 증거가 아닙니다. 실제 실행의 요청·CLI 인자·응답·영수증·완료 이벤트를 별도로 확인해야 합니다.

`historical-failure/`는 원래 실패의 014 첫 응답·015 근거 대조·016 재시도와 불변 연결을 보존합니다. 첫 crop 응답에 앞 반환 조건이 없었지만 근거 대조가 이를 요구했고, 재시도가 조건을 반복해 실제 중복으로 반려됐습니다. 기존 실제 중복 응답은 현재 회귀에서도 거절됩니다. 이번 main의 crop 3회에서는 같은 최종 실패가 재현되지 않았으며 이 차이도 기록합니다.

`interruption/`은 신규 9회와 별도입니다. 실제 완료 14호출과 완료 여부 미확인 진행 중 1호출을 구분합니다. 앞 6단위 이후 중단 92.022초, 재개 새 16호출·112.747초, 반복 새 0호출·10.015초입니다. 재개 때 앞 6단위의 불필요 호출은 0이며 기존 원고·영수증을 보존했습니다. 격리된 문서 시험이며 최종 전체 CLI 건강 검사는 별도입니다.

## 범위와 한계

브라우저 기준 텍스트·화면, 고정 자동 독자 평가의 요청·응답, 코드 검토, 동결한 시험 런타임과 실행 스크립트도 보존합니다. ZIP 생성 때 진행 중이던 전체 회귀 같은 비모델 로그는 그 시점의 부분 스냅샷입니다. 최종 CI와 최신 소스 전체 파이프라인 결과는 별도 기록을 사용하세요. 자격증명·CLI 실행 파일·가상환경·Git 저장소·사내 자료는 포함하지 않습니다. 집필 지문과 실제 요청은 보존하지만 완전한 개발 환경 설치 이미지가 아닙니다.
