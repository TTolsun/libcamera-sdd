# 최신 공개 libcamera 갱신 기록

이 파일은 PR #98 병합 전에 검증한 후보의 기록입니다. 해당 후보는 게시되지 않았습니다. 최종 갱신과 #98 보존 검증은 `integrated-c19/`에 기록했습니다.

공식 upstream과 공개 미러의 소스가 `c19d05128f3ae1f0ebe63acb4deaca9fbb1dde78`에서 일치했습니다. 직전 게시 소스 `be7e83e9…`와 비교해 파일 21개가 달라졌습니다. Clang으로 빌드하고 번역 단위 295개와 클래스 1,407개를 추출했습니다. 파싱 오류는 0개였습니다. 앞선 GCC 빌드는 Clang 추출 단계에서 C99 지정 초기화 오류를 일으켰습니다. 해당 실행과 수정 후 추출을 원본 기록에 각각 보존했습니다.

원고 25개는 현재 근거와 대조해 승계했습니다. `component-index.md`, `ipa-algorithms.md`, `pipeline-handler.md`, `pipeline-requests.md`를 다시 조립했습니다. `pipeline-handler.md`의 네 주제 답변은 재사용했습니다. Mali-C55의 `Gamma` YAML 항목과 `gamma.cpp` 빌드 등록을 분리해 설명하고, 튜닝 검색·DMA-BUF 분기·렌즈 음영 보정의 그림을 반영했습니다. #249의 요청 수명 본문과 근거 창 13개는 직전 공개판과 일치했습니다. 다섯 대표 과업의 이전 결과를 승계했으며 신규 독자 과업은 0개입니다.

영향 범위 도구는 YAML과 Meson 파일을 C++ 엔티티에 매핑하지 못해 두 건을 기록했습니다. 두 파일 전체를 현재 소스에서 발췌하고 새 본문과 직접 연결했습니다. 독립 소스 검토가 두 파일의 반영을 확인했습니다. 영향 범위 도구의 원래 판정과 사람 승인 장부를 보존했습니다. 독립 검토에서 찾아낸 취소 조건, 펜스 신호와 타이머, 셰이더 처리 순서 문제를 고친 뒤 소스·한영 검토를 다시 통과했습니다.

최종 공개 후보의 계약 검토는 86개 배치입니다. 초기 후보에서 끝낸 4개 배치는 수정 후 전체 검토 입력이 일치해 재검증했습니다. 나머지 82개에 4개 동시 실행으로 약 652초가 걸렸습니다. 이전 qcam 실험의 영수증과 일치한 배치는 0개였습니다. 정상 감사에서는 86개 원본 영수증을 다시 대조하고 12.29초에 통과했습니다. 확인된 모순은 0건입니다. 요청 제출 조건의 범위에 관한 모호함 두 건과 진단 기록의 실행 증거 부족 한 건을 남겼습니다. 이 공개판의 최초 검토와 qcam 증분 비교는 별도의 측정입니다.

사람 평가 참가자는 0명입니다. 읽기 부담과 사람 검토 시간은 미측정이며, 실기기나 사내 HAL에서의 동작도 이 범위에 포함되지 않습니다.
