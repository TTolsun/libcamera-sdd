# #242: 변경 이유와 실제 실행 판정의 연결

[생성기 PR #246](https://github.com/TTolsun/camera-hal-sdd-generator/pull/246)의 공개 검증 기록입니다. #214의 영향 밖 신규 호출 0회를 먼저 재현했습니다. 이번 변경은 일반적인 추가 호출 절감을 입증한 것이 아니라, 변경 이유·미확정 의존성·실제 판정·원본 영수증을 연결하고 JSON 정수와 불리언을 혼동한 오래된 체크포인트 재사용을 거부합니다. #241은 마지막 확인 때 열린 상태·댓글 0개였으며 발행 기준·범위·변경 이력의 새 공유 계약을 중복 구현하지 않았습니다.

## 변경별 영향과 전후 비교

두 질문·두 그림·두 번역을 가진 같은 대표 입력을 결과 확인 전에 고정했습니다. 다음은 **통제된 CLI 테스트 대역**이며 실제 모델 실행 시간이 아닙니다. 호출은 본문/근거 대조/그림/번역 순서입니다. 시간은 두 번째 생성·번역·사이트 빌드·검사의 벽시계이며 전체 작업 시간이나 병렬 호출 시간 합이 아닙니다. 기준은 최신 main `bc58d09a35e2169bc1d23d972721dd97eaa68ebb`, 변경 코드는 `6eba993dc436eed61318bf2bf5b58baff66a8bdc`입니다.

| 변경 | 전후 신규 호출 | 전후 시간(초) |
|---|---|---:|
| 동일 입력 | 0/0/0/0 → 0/0/0/0 | 0.500 → 0.538 |
| 질문 하나 | 1/1/0/0 → 1/1/0/0 | 0.572 → 0.752 |
| 근거 하나 | 1/1/1/0 → 1/1/1/0 | 0.575 → 0.687 |
| 번역 하나 | 0/0/0/1 → 0/0/0/1 | 0.476 → 0.604 |
| 그림 하나 | 0/0/1/0 → 0/0/1/0 | 0.544 → 0.518 |
| 화면 설정 | 0/0/0/0 → 0/0/0/0 | 0.614 → 0.495 |
| 결정적 검사 정책 | 0/0/0/0 → 0/0/0/0 | 0.545 → 0.606 |
| 근거 대조 정책 | 0/2/0/0 → 0/2/0/0 | 0.588 → 0.698 |
| 전역 집필 규칙 | 2/2/2/0 → 2/2/2/0 | 0.634 → 0.733 |
| CLI 프로필 | 2/2/2/2 → 2/2/2/2 | 0.696 → 0.847 |
| 미등록 의존성 | 2/2/0/0 → 2/2/0/0 | 0.621 → 0.639 |

11사례 모두 2페이지·끊어진 링크 0개·manifest 검사를 통과했고 전후 품질 결과가 같았습니다. 질문·근거·번역·그림의 실제 내용 변화, 영향 밖 본문·HTML·CSS/JS·그림과 원본 archive 보존을 함께 단언합니다. 화면 변경은 실제 title과 결과 차이를 확인했으며 파일 이름만으로 의미상 영향이 없다고 분류하지 않았습니다. 이 작은 대역 시험의 시간 차이를 속도 개선으로 해석하지 않습니다. 전체 worker 시간은 입력 준비를 포함해 15.848 → 16.827초입니다.

결정적 검사 정책은 기존 결과를 현재 검사로 재검증합니다. 근거 대조 정책은 두 답변 모두 새 검토를 유지합니다. 전역 집필 규칙은 두 본문·검토·그림을, CLI 프로필은 모든 네 종류를, 알 수 없는 식별자 의존성은 두 본문·근거 검토를 다시 수행합니다. 미등록 의존성을 무시하거나 정책 해시를 제외하지 않았습니다. `1`에서 `true`로 바꾼 식별자는 유효한 과거 archive를 현재 예상 파일명으로 옮겨도 거부합니다. 수정 전 1개 실패와 수정 후 통과 결과 및 양쪽 원본 시험 파일을 보존합니다.

## 실제 지정 CLI와 독립 검토

공개 libcamera 분석 커밋 `293d751a814e0d4c34e85ad457ccd9d5eefd1a61`의 camera.cpp 두 API 문서 창을 원본 Git 문자열·시작 줄과 대조한 뒤 실제 Codex CLI `gpt-6.1-terra` / `model_reasoning_effort="high"`를 실행했습니다. 생성·내부 근거 대조는 별도 네이티브 호출이며 독립 검토는 별도 설정으로 다시 실행했습니다. 명령·모델·인자의 실효값과 request/response/stdout/receipt를 archive에 보관합니다. 다른 CLI·직접 API·저장 응답을 신규 실행으로 대체하지 않았습니다.

| 실제 실행 | 신규 호출 | 벽시계(초) | 호출 시간 합(초) |
|---|---:|---:|---:|
| 두 질문 최초 생성·근거 대조 | 4 | 21.5656 | 20.7375 |
| 동일 입력 재개 | 0 | 0.4072 | 0 |
| 질문 하나 변경 | 2 | 11.2085 | 10.6669 |

각 실행은 2페이지·끊어진 링크 0개·manifest 검사를 통과했습니다. 독립 Codex CLI는 상태·오류·스레드 안전성 설명이 제공된 API 계약에 부합한다고 판단했습니다. 짧은 개별 질문은 상태·반환값 목록으로 충분하다는 그림 생략 이유도 기록했습니다. 표본 glossary의 API/LLM 약어 경고 2개는 남아 있으며 검사 통과를 경고 없음으로 표현하지 않습니다. 최종 코드 재개는 신규 호출 0회·0.5679초이며 원본 네이티브 파일 30개를 보존했습니다. 최초 정상 원고·사이트도 archive에 그대로 남아 있습니다.

## 기존 공개 문서의 재검증과 보존

공식 upstream과 공개 upstream/master는 `be7e83e91348250c015aad6d6f59f1468555bae8`로 일치합니다. 분석 기준 이후 변경은 meson.build, AGC 추정기, Python 바인딩 세 파일입니다. 현재 문서의 42개 upstream 근거 파일과 겹치지 않으며 별도 product-evidence 9개는 과거 시험 범위로 유지합니다. 분석·원래 runtime 기준 293을 최신 소스 전체 검증으로 바꾸지 않았습니다.

최신 공개 main `178aa978890a22df5e984bc5efe18a1a3756aa1b`의 #247 드래그 기능과 검토된 번역 카탈로그를 보존했습니다. 정상 export 두 번은 26.1860초와 29.6392초였고 manifest 및 328개 산출물 바이트가 일치했습니다. 62페이지·끊어진 링크 0개·manifest 검사를 통과했습니다. 6개 검토 계약의 기존 88배치를 현재 결정적 검사로 각각 재검증했으며 신규 모델 호출은 0회입니다. 원본 네이티브 4,099개 파일의 목록과 해시가 복원 색인과 완전히 같았습니다. 최신 공개 328개 출력도 그대로이며 새 manifest는 이번 생성기 실행을 식별합니다. HTML을 직접 고치지 않았습니다.

기존 자동 insufficient-evidence 두 건과 사람 검토 pending은 보존합니다. 이번 시험은 #215 전체 시각화, #163 전체 독자 평가, 새 실기기 또는 사내 HAL 검증의 완료가 아닙니다. 독립 코드 검토의 과거 지적·실패·재시도도 삭제하거나 사람 승인으로 승격하지 않습니다. 생성기 PR #246은 `dd5daa32774ee873f6faf669f63ef2557d88c717`로 병합됐습니다. 최종 헤드의 [CI](https://github.com/TTolsun/camera-hal-sdd-generator/actions/runs/41890463774)는 Linux 3.11/3.14 각각 2,633개 통과, Windows 3.11/3.14 각각 2,632개 통과·1개 생략입니다. 병합 트리와 검증한 트리는 같으며 최종 소스 해시도 일치합니다. 배포 후 증거는 공개 PR과 원래 이슈 완료 댓글에 연결합니다.

## 증거와 재현

- `matrix-comparison.json`: 같은 전체 입력 해시, 전후 호출·시간·품질과 예측 기록입니다.
- `native-and-regression-evidence.zip`, `archive-index.json`: 실제 CLI 표본·이전 정상 출력·독립 코드 검토·행렬 대역 archive와 JSON 형식 경계 시험 원본입니다. `evidence-package.json`으로 zip 자체도 확인합니다.
- `typed-before.xml`, `final-regressions-10.xml`: 수정 전 실패와 수정 후 96 passed / 1 skipped입니다. 최초 CI의 8개 legacy spy 실패는 기존 지문 단언을 유지하고 선택 인자를 받도록 수정했으며 실패 기록을 지우지 않았습니다.
- `final-input-audit.json`, `two-exports-final.json`, `site-manifest.json`: 소스·프로필·기존 영수증·재검증 판정·산출물 해시입니다.
- `release-inputs`, `restore_public_release.py`: 기존 [통합 archive](../issue211-virtual/integration)에서 `workspace/current-main-integration/`을 복원한 뒤 경로만 옮깁니다. 원본 facts·보고서·영수증을 바꾸지 않고 최신 [그림 드래그 카탈로그](../diagram-pan/english.json)를 사용합니다. source checkout은 293이며 과거 compile database는 신규 추출 실행으로 간주하지 않습니다. 기존 Mermaid 자산과 원본 manuscript도 보존합니다.

실제 CLI 재현은 archive의 actual-probe-02/sdd.yaml과 별도 independent-review.yaml 경로를 현재 환경에 맞게 옮기고 선택 CLI의 명령·모델·인자를 확인해야 합니다. 과거 receipt를 확인할 때는 역사적 명령의 원래 값도 보존합니다. CLI가 없거나 실패하면 미완료로 보고해야 하며 archive는 새 호출의 대체물이 아닙니다. 행렬은 생성기에서 `python tools/benchmark_issue242.py --baseline-ref bc58d09a35e2169bc1d23d972721dd97eaa68ebb --out <새 경로>`로 실행합니다.

이 문서는 수치·판정을 표로 직접 비교하므로 별도 그림을 생략합니다. 예측과 실제 판정의 관계 그림은 생성기의 [재사용 경계 문서](https://github.com/TTolsun/camera-hal-sdd-generator/blob/main/docs/concepts/reuse-boundaries.md)에 있습니다.
