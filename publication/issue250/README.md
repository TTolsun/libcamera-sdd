# 같은 근거를 작업과 결정으로 연결한 공개 사례

생성기 [PR #257](https://github.com/TTolsun/camera-hal-sdd-generator/pull/257)은 병합됐습니다. 공개 libcamera의 제출 성공·완료 누락 시나리오에서 기존 Vendor/Developer를 유지하고, 파트원의 다음 조사 작업과 기술 의사결정자의 문제·가치·위험·선택지·다음 결정으로 진입점을 나눴습니다. 상세 답변과 소스 근거의 소유자는 기존 공통 원고입니다.

실제 비작성자 사람 평가와 실제 임원 평가는 수행하지 않았습니다. 사내 HAL도 검증하지 않았습니다. 이슈 #250 전체를 완료하거나 이 대리 평가를 임원 공감 검증으로 해석하지 않습니다.

## 확인한 공개 결과

한영 66페이지의 끊어진 링크는 0개이며 반복 내보내기의 manifest가 같습니다. 한영·데스크톱·모바일에서 두 진입점, 키보드 진입, 근거 링크, 기존 Vendor/Developer와 새 질문 그림 다섯 개의 렌더링·확대·검색을 확인했습니다. Pipeline Handler 원고 한 개의 네 주제를 현재 Codex CLI/Terra High와 집필 규칙으로 생성하고, 원문의 정확한 같음 조건·잠금 반복·해제 순서·구성 계약·입력 탐색식과 그림을 보완했습니다. 최신 공개 #243·#248을 통합했고 나머지 28개 원고와 모든 기존 facts 항목을 보존했습니다. facts 추가 한 개는 #243에서 이미 공개한 입력입니다.

[전체 CI 네 조합](https://github.com/TTolsun/camera-hal-sdd-generator/actions/runs/41913047846)이 통과했습니다. 최종 계약 감사는 여섯 그룹의 문장 502개를 대조했고 명시적 충돌은 없습니다. 마지막 실행은 새 배치 두 개와 원본 영수증을 재검증한 85개를 사용했습니다. 독립 그룹에서 기본 인자의 발췌 범위를 불충분하다고 본 기록도 지우지 않았습니다. 자동 판정은 사람 승인이나 모든 소스 의미의 증명이 아닙니다.

변경된 한영 문장 104개의 마지막 독립 대조에는 추가 지적이 없습니다. 완료된 실제 CLI 영수증 297개의 무결성을 검증했으며 복사본 39개를 새 호출로 중복 집계하지 않았습니다. 이 수는 생성·번역·검토와 거절된 제안을 포함하며, 승인된 원고나 사람 평가 횟수가 아닙니다. 이번에 새로 실행한 생성·번역·별도 근거 대조는 지정된 Codex CLI / gpt-6.1-terra / high로 수행했고 수동 원고나 저장 응답을 새 실행으로 대체하지 않았습니다. 보존한 28개 원고의 과거 작성 모델·인자는 당시 값 그대로입니다.

## 작성 맥락을 주지 않은 대리 독자

두 신규 에이전트는 작성 대화·설정·정답표·이전 평가 없이 같은 HTML과 내장 소스 발췌만 읽었습니다. 각 평가 전후 build ID가 같았습니다. [사전 과제](final-evaluation-tasks.json), [파트원 실제 응답](evaluation-final-work.json), [기술 의사결정자 실제 응답](evaluation-final-decision.json)을 공개합니다.

| 역할 | 찾은 내용과 남은 내용 | 과제별 주관적 관련성 |
|---|---|---|
| 대리 파트원 | 제출 반환값·준비 대기·장치 실패·완료 반환의 파일·함수·값·분기와 수명·수정 후 확인을 찾았습니다. 실제 장치 구현·담당자·완료 판정 시간은 미발견입니다. 조사·검증의 구체적 관찰표는 상세 문서로 이동해야 합니다. | 4·5·4·4/5점입니다. |
| 대리 기술 의사결정자 | 확인한 정적 성질, 효용 가설·미측정 효과와 착수·보류·추가 입력을 구분했습니다. “즉시 완료”를 콜백 종료 시점으로 확대 해석하지 않으려면 상세 조건까지 읽어야 한다고 답했습니다. 실제 장애 원인·정량 합격선은 미발견입니다. | 5·4·5·4·5/5점입니다. |

점수는 에이전트의 주관적 응답이며 실제 사람의 이해·만족도·작업 성과·기간 단축률·ROI가 아닙니다. 사람 결과 CSV에는 헤더만 있으며 실제 참여자는 0명입니다. 실제 비작성자 두 역할 각 1명 이상의 답변·방문 경로·오해·관련성과 공개 동의를 같은 배포본에서 확보해야 합니다. 실제 임원 참여 여부도 별도로 기록해야 합니다.

## 적용 경계와 남은 위험

facts와 원고는 libcamera 293d751a814e0d4c34e85ad457ccd9d5eefd1a61에 고정했습니다. 관측한 공식 upstream과 공개 mirror는 be7e83e91348250c015aad6d6f59f1468555bae8입니다. 대표 경로와 재생성 주제의 근거 창 67개가 변경되지 않았음을 전체 Git 변경 경로와 대조했습니다. 최신 커밋의 전체 추출·AGC·Python 구성 API·버전 변경이나 새 장치 실행을 완료하지 않았습니다. 과거 가상 프로브를 새 실행으로 바꾸지 않았습니다.

마지막 원문 검토의 탐색성 제안 한 건은 첫 탐색과 재초기화 사이에도 순서 간선을 추가하자는 것입니다. 현재 본문과 노드는 순서를 명시하고 그림은 중첩 구조와 별도 계산을 표현합니다. 이 제안을 반영 완료로 표시하지 않으며, 사이트 전체 그림 보완이나 #215·#249 완료를 주장하지 않습니다.

[사내 양식](https://github.com/TTolsun/camera-hal-sdd-generator/blob/main/examples/inhouse-template/config/reader-paths.yaml)은 ready:false입니다. 실제 소스·빌드·장치·재현·계측·검토 책임·결정 권한·게시 경계와 승인된 생성 및 독립 검토 CLI 설정이 필요합니다. 개발 기간 단축률·ROI·사내 조직 역할을 추정하지 않았습니다. 역할 설정의 사람 승인을 기록하는 CLI가 없어 require_approval:true 게시를 차단합니다.

## 증거와 재현 범위

[사이트 검사](site-verification.json), [화면·동작 검사](browser-verification.json), [원본 영수증 대조](native-verification.json), [소스 창](source-scope.json), [요약](release-summary.json), [패키지 해시](package.json)를 구분해 확인할 수 있습니다. native-and-public-evidence.tar.gz와 archive-index.json은 선택 CLI의 요청·응답·stdout·영수증, 거절·중단 기록, 최종 원고·설정·facts·집필 규칙과 실행 스크립트를 보존합니다. record.md는 앞선 작업 과정과 첫 비공개 미리보기 평가 기록입니다. 최종 대리 평가의 기준은 위 JSON입니다.
