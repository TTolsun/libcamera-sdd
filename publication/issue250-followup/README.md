# #250 후속: 적용 조건, 직접 탐색과 검색 순서

파트원은 조사·검증 질문에서 공통 상세 설명으로 바로 이동하고, 기술 의사결정자는 정지의 오류 완료가 모든 애플리케이션 콜백의 실행·반환 완료를 뜻하지 않는다는 조건을 인용문보다 먼저 읽습니다. 실제 장애 조사와 문서 근거 탐색 평가도 서로 다른 결정으로 표시합니다. Pipeline Handler 그림은 첫 번째 중첩 검색 전체를 빠져나온 뒤 reset하는 순서를 연결합니다. 내부 반복 종료만으로 reset하거나 검색의 종료를 보장한다는 뜻이 아닙니다.

공통 본문과 기술 근거의 소유권은 기존 상세 설명에 있습니다. 사실을 새 요약 원고로 바꾸지 않았고, 역할 진입점의 질문·조건·직접 링크를 생성 경로에서 개선했습니다. 그림은 지정 Codex CLI / gpt-6.1-terra / high로 생성했습니다. 기존 네 그림의 원본 기록과 설명 원고는 유지하고 한 그림만 교체했습니다. 생성된 HTML은 직접 수정하지 않았습니다.

[생성기 PR #274](https://github.com/TTolsun/camera-hal-sdd-generator/pull/274)는 `564b49868594ea5526472761de0752ca93bcd6d5`로 병합됐습니다. 55개 표적 시험과 Linux·Windows, Python 3.11·3.14 CI를 통과했습니다. 공개 입력 통합에서는 먼저 반영된 #243의 선언 근거·원고 보정과 검증 하위 사이트를 보존했습니다. 공식 upstream에서 확인한 분석 소스는 `be7e83e91348250c015aad6d6f59f1468555bae8`이며 기존 #249 추출을 재사용했습니다. 새 전체 추출이나 카메라 실행을 했다는 뜻이 아닙니다.

## 평가와 확인 범위

파트원 네 과제와 기술 의사결정자 다섯 과제를 사전에 고정했습니다. 작성 맥락·설정·이전 평가를 주지 않은 별도 서브에이전트가 같은 build ID의 문서와 그 근거를 읽고 실제 답변·방문 위치·오해·미발견 항목·주관적 관련성을 기록했습니다. `evaluation-final-*.json`은 이 **대리 평가**이며 실제 사람이나 임원이 아닙니다. 브라우저 동작 확인은 별도 `browser-verification.json`에 있습니다.

최종 대리 평가의 주관적 관련성은 두 역할 모두 4/5입니다. 두 역할은 직접 상세 링크와 정지·콜백의 보장 한계를 찾았고, 파트원은 첫 중첩 검색 전체 종료 뒤 reset하는 순서를 구분했습니다. 실제 실행 입력·장치별 계측·합격 임계값은 추가로 필요합니다. 이 점수는 실제 독자의 이해나 개선률을 측정하지 않습니다.

최초 후속 평가 뒤에는 연결 방식별 과거 관측표와 반환 근처 표시의 한계에도 직접 링크를 추가했습니다. 동시 공개 main을 통합해 build ID가 달라진 뒤에는 평가를 다시 수행했습니다. 이전 build의 평가를 현재 build의 사람 승인으로 바꾸지 않았습니다. 자동 대조, 구조 검증, 대리 평가와 사람 검토는 각각 구분합니다.

반복 정상 export, 페이지·내부 링크, 한영 데스크톱·모바일 화면과 직접 링크·그림 확대·검색을 확인합니다. 최종 build와 수치는 `site-verification.json`, `browser-verification.json`, `evaluation-trace-verification.json`에 있습니다. Pages 실행 및 실제 공개 바이트 확인 결과는 이 기록을 반영한 공개 PR에서 확인합니다.

## 남은 위험과 필요한 입력

- 실제 파트원·기술 의사결정자·임원의 문서 이해와 공감은 미검증입니다. 실제 비작성자 각 역할의 과제 수행·자기 설명·오해와 주관적 관련성 기록이 필요합니다. 이 패키지로 이슈 전체나 사람 평가를 완료 처리하지 않습니다.
- 공개 libcamera 사례는 사내 HAL의 구조·승인 체계·성과를 확인하지 않습니다. 사내 소스·빌드·코드 링크·게시·승인된 생성/번역/독립 검토 CLI 설정, 실제 역할·결정 권한, 사건 재현·실행 로그와 허용 오차가 필요합니다. 입력이 비어 있으면 사내 템플릿 게시를 막습니다.
- 가상 CPU 관측은 과거 커밋과 제한된 실행 창의 기록입니다. 실제 장치의 지연·드롭·정지 안전성·원인이나 모든 콜백의 반환 완료를 증명하지 않습니다. 반환 근처 표시 역시 완전한 반환 뒤 관측이 아닙니다.
- 상세 설명의 발췌 묶음과 문단 사이에는 독자의 추가 대조가 남습니다. 콜백 링크의 제목 다음 조건과 관측표를 함께 읽어야 합니다. 문서 평가의 배경 근거와 실제 평가 실행 양식의 연결도 추가 개선 여지가 있습니다. 전체 사이트의 표현·그림·모든 독자 과업을 완전 검증했다고 하지 않습니다.
- 개발 기간 단축률·품질 개선률·ROI는 측정하지 않았습니다. 기술적 성질, 관측, 가설·미측정 효과, 필요한 결정을 서로 다른 상태로 유지합니다.

## 원본과 재현 경계

`native-and-public-evidence.tar.gz`와 `archive-index.json`은 실제 CLI 요청·응답·원시 stdout·영수증, 중간 실패와 검증·입력·원고의 바이트를 고정합니다. 생성 CLI가 완료된 뒤 로컬 CRLF 조립 검사가 실패했던 시도는 보존했습니다. 완료된 원본 산출물로 조립을 재개한 일을 새 CLI 실행으로 세지 않았습니다. 한영 검토 결과를 저장한 뒤 터미널 cp949 출력만 실패했던 기록도 남습니다.

통합해 가져온 #243 완료 영수증과 이번 작업의 완료 영수증은 `native-verification.json`에서 구분하며, 기존 체크포인트의 현재 입력 재검증을 새 모델 호출로 세지 않습니다. 공통 계약 감사의 다른 범위에 남은 불확실성은 현재 보고서에 그대로 있습니다. 승인이나 사이트 전체 의미 정확성의 증명은 아닙니다.

입력 프로필에는 원래 로컬 경로가 남습니다. 다른 호스트에서 재현하려면 보관된 공개 #249·#243 입력 패키지를 준비하고 경로를 다시 연결해야 합니다. 저장 응답을 새 CLI 실행으로 재생해 성공으로 보고할 수 없습니다. 사내 원본·파생 자료는 포함하지 않았습니다. 이 실행 기록은 표와 원본 참조로 대조할 수 있어 장식 그림을 추가하지 않았습니다.
