# #243 반복 지적의 원인과 실제 보정 증거

현재 상태는 **생성기 병합·소스 대조·정적 빌드 완료, 화면 검증·공개 배포 미완료**입니다. [생성기 PR #258](https://github.com/TTolsun/camera-hal-sdd-generator/pull/258)은 `41c4ba2a9d85b8566c13605b902e2147b6bca8df`로 병합됐습니다. [원래 이슈 #243](https://github.com/TTolsun/camera-hal-sdd-generator/issues/243)은 모든 완료 조건을 충족한 뒤 닫습니다.

## 반복 원인과 확인한 효과

고정한 과거 libcamera 기록에서는 같은 한국어 null 반환 레이블에 서로 다른 영어 어순이 연결됐습니다. 다음 호출은 위치·충돌한 번역 쌍 없이 같은 일반 오류 문구만 받았고 충돌을 반복했습니다. 후속 고정 노드 우회는 형식 오류를 없앴지만 null 반환 전 구성 생성 성공을 단정하는 의미 오류를 만들었습니다. 새 독립 소스 검토가 이전 초안과 후속 초안의 차이를 확인했으므로 오류 A 해결·오류 B 발생을 전체 수정 성공으로 세지 않습니다. 원본 해시와 과거/신규 실행의 구분은 [생성기 기록](https://github.com/TTolsun/camera-hal-sdd-generator/blob/main/docs/records/issue243.md)과 그 증거 archive에 있습니다.

이 표본에서는 호출 감소나 속도 향상을 입증하지 못했습니다. 별도 소스 검토·코드 리뷰와 환경 실패는 위 보정 호출 수에 합치지 않았습니다. CLI 시간 초과만으로 일시적 서버 장애를 확정하지 않습니다.

## 이번 공개 페이지의 실제 변경

`vendor-assurance`의 roles 충족/미충족 반환 질문에 세 노드의 그림을 추가했습니다. 성공 여부가 갈리기 전 노드는 생성 요청을 설명하며, 요청 역할을 충족하면 유효 구성, 충족하지 못하면 null을 반환하는 계약을 보여 줍니다. 실제 장치가 해당 역할을 지원한다는 보장이 아닙니다.

별도 검토는 기존 validate 그림의 무조건적인 조정 표현과 두 변경 가능성을 결합한 한국어 표현을 지적했습니다. 그 초안은 기존 공개 초안과 같았으므로 새 그림 때문에 생긴 오류로 세지 않았습니다. 소스의 `possibly adjust` 및 각각의 `may`를 수정 지시에 명시한 뒤 지정 CLI로 해당 그림만 보정했습니다. 설명 10개와 roles/null 그림은 기존 관문으로 재사용했습니다. 최종 소스 대조에서 두 지적이 해결됐고 선택 범위의 재발·새 의미 오류는 없었습니다.

| 이번 공개 작업의 신규 실제 CLI | 호출 수 | 구분 |
| --- | ---: | --- |
| 선택 페이지 최초 생성·내부 근거 대조 | 22 | 설명 10개와 그림 2개를 생성·검사했습니다. |
| validate 그림의 의미 보정 | 1 | 설명 10개를 재사용하고 해당 그림만 다시 생성했습니다. |
| 영어 번역 | 2 | 9개 입력 중 자리표시자를 중복한 1개만 다시 요청했습니다. 저장 문자열 8개가 바뀌었고 1개는 같은 번역으로 재검증됐습니다. |
| 별도 소스·한영·메타데이터 검토 | 6 | 이전 지적·근거 부족 판정을 보존하며 누락 근거를 추가했습니다. 마지막에는 줄 범위·날짜만 좁혀 검토했습니다. |
| 기존 문서 간 계약 검토 | 0 | 기존 88배치를 현재 입력과 원본 영수증으로 재검증했습니다. |
| 합계 | 31 | 복사·재검증한 과거 영수증을 새 호출로 세지 않았습니다. |

최초 선택 페이지 생성의 벽시계는 181.9472초, 의미 보정 실행은 20.5576초입니다. 별도 검토·번역은 일부 병행했으므로 단계 시간을 합쳐 전체 벽시계나 속도 절감률로 표시하지 않습니다. 전체 10시간 발행의 재측정이나 사람의 읽기 부담·검토 시간 측정도 아닙니다.

독립 검토 입력에서 클래스 선언문과 번역된 발췌 메타데이터가 빠져 근거 부족이 발생한 기록도 남겼습니다. 이를 원고 오류로 바꿔 다시 작성하지 않았습니다. 실제 Git 선언문, 기존 `for_source` 문맥 결합, 결정적 줄 범위 검사와 생성 기록을 추가해 해당 검토 범위만 확인했습니다. 이전 `insufficient-evidence` 응답은 삭제하거나 통과 응답으로 고치지 않았습니다. 소스·영어 의미와 UI 메타데이터의 최종 대조는 같은 원고·카탈로그 해시에 연결돼 있습니다.

## 보존·검증 범위

- 기존 네이티브 파일 4,099개와 다른 원고 28개는 바이트가 같습니다. CLI·체크포인트·사람 검토 상태를 승격하지 않았습니다.
- 정상 export 두 번의 manifest와 330개 소유 산출물이 같고, 62페이지·끊어진 내부 링크 0개·manifest 검사를 통과했습니다. HTML을 직접 수정하지 않았습니다.
- 분석 기준은 공개 libcamera `293d751a814e0d4c34e85ad457ccd9d5eefd1a61`입니다. 공식 upstream과 공개 mirror는 `be7e83e91348250c015aad6d6f59f1468555bae8`로 일치합니다. 이후 변경 세 파일은 기존 42개 소스 근거 파일과 겹치지 않으며 새 전체 추출·장치 실행·사내 검증을 뜻하지 않습니다.
- 기존 공통 계약의 자동 `insufficient-evidence` 두 건과 사람 검토 전 상태는 보존합니다. #215 전체 그림 보완과 #163 전체 독자 평가는 이 작업의 완료로 간주하지 않습니다.
- 이번 턴에는 Windows의 현재 URL을 검증하지 못해 Computer Use가 종료됐습니다. 새 산출물의 데스크톱·모바일·확대 동작, Pages와 공개 산출물 대조는 미완료이며 다른 UI 제어로 우회하지 않았습니다.

생성기 [최종 CI](https://github.com/TTolsun/camera-hal-sdd-generator/actions/runs/41899270217)는 Linux 3.11·3.14 각각 2,720개 통과, Windows 3.11·3.14 각각 2,719개 통과·1개 생략입니다. 병합 트리의 `src/sdd` 및 #243 시험은 검증한 헤드와 같고, 동시 병합된 평가 도구의 7개 시험도 로컬에서 통과했습니다. 실패했던 이전 CI와 중단한 중복 로컬 전체 실행은 성공으로 세지 않습니다.

## 원본과 재현

`native-and-operation-evidence.tar.xz`와 `archive-index.json`은 이번 작업의 신규 원본 CLI 요청·응답·stdout·영수증, 입력·변경·지적·다음 조치, 독립 검토와 실패 기록을 묶습니다. `package.json`은 archive·색인의 해시를 고정합니다. `native-call-verification-issue243.json`은 선택한 CLI와 실제 원본 출력을 대조한 결과입니다. 테스트 대역이나 저장 응답을 신규 CLI 성공으로 사용하지 않았습니다.

`facts293.json.gz`, archive의 `operation/config`·집필 규칙·프로필·카탈로그와 새 원고는 실제 입력 스냅샷입니다. 원래 경로·모델·인자를 보존했으므로 다른 환경에서는 입력 설정의 경로만 명시적으로 재배치해야 합니다. 과거 원본은 [#211 통합 archive](../issue211-virtual/integration), [#242 복원 기록](../issue242/README.md), [기존 반환 진단 입력](../submission-diagnosis/README.md)을 참조합니다. CLI 영수증·과거 프로필을 현재 값으로 다시 쓰지 마세요. 기본 생성·번역과 별도 검토는 모두 Codex CLI / `gpt-6.1-terra` / high였고, 역사적 Claude 등의 프로필은 원고 인증에만 사용했습니다.

검토·실행 전후와 미완료 상태는 표·원본 기록으로 직접 비교할 수 있으므로 이 증거 설명의 별도 그림은 생략합니다.
