# 로컬 Qwen 문서 갱신 시험

8개 설명 문서에서 기준 생성, 소스 변경, 복원, 공식 커밋 이월을 실행했습니다. `proof.json`은 채택한 실제 Ollama HTTP 요청·응답, 원고와 발췌 해시, 변경 영향, 실행 상태를 보존합니다. 문장을 수작업으로 고친 응답 묶음은 사용하지 않았습니다.

`python verify_document_replay.py .`로 원응답·인용·단계별 원고를 독립 검증할 수 있습니다. 배포 원고가 인접한 `../docs/`에 있으면 그 바이트도 비교합니다. 시험 커밋은 로컬 검증용이며, 공개 문서는 공식 upstream의 소스로 이월한 결과입니다.

시험 값은 측정 프레임 30→12→30, 준비 대기 300ms→150ms→300ms, LSC 최대 수평 셀 73→65→73, 접근 오류 EACCES→EPERM→EACCES, DW100 허용 계수 12개 제거·복원과 IPA 프록시 조건 변경·복원입니다. 클래스·필드·함수 호출 추가와 제거는 LLM 설명과 별도로 구조 색인·관계도·호출 시나리오에 대조했습니다.

변경·복원 단계마다 실제 WSL 빌드와 300개 번역 단위 추출을 마쳤고 파싱 오류는 0개였습니다. 같은 커밋에서 생성만 재시도할 때에는 추출 입력과 facts 해시를 검사하고 이전 실제 추출을 재사용했다고 로그에 명시했습니다. 소스가 같은 재실행은 추가 모델 호출 없이 종료했습니다.

모델은 qwen3.5:9b, temperature 0.1, think=false, num_ctx=16384, 출력 한도 2000, 재시도 2회입니다. 검증된 답변 체크포인트를 사용했으며, 변경된 소스 근거의 주제는 다시 생성하고 같은 근거의 주제는 재검증해 이월했습니다. 각 변경·복원에서 16개 주제를 생성하고 27개를 이월했습니다.

이는 공개 libcamera의 통제된 변경 시험입니다. 임의의 코드 변경에 대한 의미 정확성, 사람 승인, 사내 HAL 적용 또는 장치 검증을 뜻하지 않습니다. 과거 실패 기록과 기존 개요 시험은 별도 기록으로 유지합니다.
