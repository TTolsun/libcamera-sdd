# libcamera design documentation

[Public Korean and English documents](https://ttolsun.github.io/libcamera-sdd/) support dragging the desktop sidebar boundary to resize it. Titles wrap automatically, the width persists across pages and editions, and double-click resets it. [Current update and checks](publication/sidebar-resize/README.md) cover 46 HTML pages, no broken links, identical repeat builds and Chrome interaction checks. Metadata and frame buffer glossary entries now explain terms already used in the request, buffer and IPA categories.

Existing facts, manuscripts, original generation times, model labels and review states are preserved. This update makes no fresh extraction or CLI inference claim. GitHub Pages deployment is checked separately from the local build; its live status is available in repository deployments. Human approval, internal HAL validation and device validation are not established.
