ColourTemperature requests and results

ColourTemperature is an inout control value that represents the frame's colour temperature in kelvin and can be applied in a request only when AWB is disabled. The ColourTemperature used to process the frame is reported in metadata. If ColourTemperature is set in a request and ColourGains is not set, the implementation must calculate and set ColourGains based on the specified colour temperature. If ColourTemperature is set directly or indirectly by setting ColourGains and ColourCorrectionMatrix is not set, ColourCorrectionMatrix is updated based on ColourTemperature.

If ColourTemperature is present, the Raspberry Pi IPA's request processing code silently ignores that control value for a mono sensor. If it cannot find an AWB algorithm, it logs a warning and ends that processing. Otherwise, it calls the AWB algorithm's setColourTemperature(), then sets awbEnabled_ to false, switching AWB to manual mode. If awb.status is present, the metadata processing code sets temperatureK from that status as the ColourTemperature metadata.

const auto colourTemperature = controls.get(controls::ColourTemperature);
    if (colourTemperature)
        do {
            /* Silently ignore this control for a mono sensor. */
            if (monoSensor_)
                break;

            auto temperatureK = *colourTemperature;
            RPiController::AwbAlgorithm *awb = dynamic_cast<RPiController::AwbAlgorithm *>(
                controller_.getAlgorithm("awb"));
            if (!awb) {
                LOG(IPARPI, Warning)
                    << "Could not set COLOUR_TEMPERATURE - no AWB algorithm";
                break;
            }

            awb->setColourTemperature(temperatureK);
            awbEnabled_ = false; /* doing this puts AWB into manual mode */

            /* This metadata will get reported back automatically. */
            break;
        } while (false);
