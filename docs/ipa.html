IPA 모듈 선택, 스레드·프로세스 경계와 요청·결과 인터페이스를 구현 근거로 확인하세요.

이 문서의 용어: IPA, IPC, 튜닝 파일, 소프트웨어 ISP 외 6개
  • IPA (Image Processing Algorithms): 화질 알고리즘을 담은 별도 모듈(.so)입니다. ISP가 보낸 통계를 보고 다음 프레임에 쓸 ISP 설정값을 계산합니다. 제조사가 소스를 공개하지 않고 제공할 수 있도록 libcamera 본체와 분리되어 있습니다.
  • IPC (Inter-Process Communication): 서로 다른 프로세스가 메시지를 주고받는 방식입니다. 서명이 없는 IPA 모듈은 별도 프로세스에서 실행되므로 libcamera가 IPC로 호출합니다.
  • 튜닝 파일: 센서와 플랫폼별 알고리즘 매개변수(보정 표, 색 행렬 등)를 담은 YAML 파일입니다. IPA가 시작할 때 읽습니다.
  • 소프트웨어 ISP: 하드웨어 ISP가 없는 장치에서 CPU나 GPU로 ISP 처리를 대신하는 libcamera 구성 요소입니다. 소스에서는 software_isp, softisp라는 이름을 씁니다.
  • ISP (Image Signal Processor): 센서가 출력한 원시(bayer) 데이터를 화면에 쓸 수 있는 영상으로 바꾸는 처리 장치입니다. 블랙 레벨 보정, 렌즈 음영 보정, 화이트 밸런스, 디베이어 등을 수행합니다.
  • 셰이더: GPU에서 실행되는 작은 프로그램입니다. 소프트웨어 ISP는 디베이어와 색 보정을 GPU 셰이더로 수행할 수 있습니다.
  • LSC (Lens Shading Correction): 렌즈 특성 때문에 영상 가장자리가 중앙보다 어둡거나 색이 틀어지는 현상(렌즈 음영)을 보정하는 처리입니다. 화면을 격자로 나눈 보정 표를 곱해서 적용합니다.
  • 프록시: IPA 모듈을 직접 부르지 않고, 같은 인터페이스로 호출을 받아 IPA 스레드나 별도 프로세스로 전달하는 대리 객체입니다. 빌드할 때 mojom 정의에서 자동 생성됩니다.
  • RKISP1 (Rockchip Image Signal Processor 1): Rockchip SoC와 NXP i.MX8MP 등에 들어 있는 카메라 ISP입니다. libcamera에는 이 장치용 Pipeline Handler와 IPA가 있습니다.
  • IPU3 (Intel Image Processing Unit 3): 일부 Intel 노트북 프로세서에 들어 있는 카메라 ISP입니다. libcamera에는 이 장치용 Pipeline Handler와 IPA가 있습니다.

다른 용어는 용어집에서 찾을 수 있습니다.

Threaded start 템플릿 분기는 먼저 state_를 ProxyRunning으로 설정하고 thread_.start()를 호출합니다. 이어서 proxy_.invokeMethod()로 ThreadProxy::start를 ConnectionTypeBlocking 연결 유형과 템플릿의 메서드 매개변수로 호출하고 그 반환값을 반환합니다. 생성된 Threaded 메서드는 init, start, stop이 아닌 일반 동기 메서드 분기에서 ipa_의 같은 이름 메서드를 전달받은 매개변수로 직접 호출하고 그 반환값을 반환합니다. 비동기 메서드 분기에서 ASSERT 매크로는 state_ == ProxyRunning 식을 검사합니다.

Threaded 비동기 분기에서 proxy_.invokeMethod는 ThreadProxy 메서드를 전달할 때 연결 유형으로 ConnectionTypeQueued를 사용합니다. {{proxy_name}}Threaded 생성자는 ipam->load()를 호출합니다. 호출 결과가 거짓이면 생성자는 즉시 반환합니다.

{{proxy_name}}Threaded 생성자는 ipam->load()가 성공하면 ipam->createInterface()를 호출합니다. 반환된 포인터가 없으면 ipam->path()를 포함한 오류를 기록하고 생성자에서 반환합니다.

생성된 {{proxy_name}}Threaded 생성자는 ipam->load()가 실패하거나 ipam->createInterface()가 null을 반환하면 연결 전에 반환합니다. 그 외에는 ipa_를 설정하고 proxy_.setIPA(ipa_.get())를 호출한 뒤, 각 IPA 이벤트의 connect에 수신 객체 this와 해당 이벤트의 {{proxy_name}}Threaded::{{method.mojom_name}}Handler 메서드를 전달합니다. 연결 코드는 템플릿의 interface_event.methods 항목마다 생성되며, 그 뒤 생성자는 valid_를 true로 설정합니다.

{{proxy_name}}Isolated 생성자는 resolvePath("{{module_name}}_ipa_proxy")로 worker 경로를 구하고, 경로가 비어 있으면 오류를 기록한 뒤 반환합니다. 경로가 있으면 IPA 모듈 경로와 worker 경로로 IPCPipeUnixSocket을 생성하고, 연결되지 않았다면 오류를 기록한 뒤 반환합니다. 연결되면 recv를 recvMessage에 연결하고 IPC 객체를 ipc_로 이동한 뒤 valid_를 true로 설정합니다.

{{proxy_name}}Isolated 생성자는 워커 경로가 비어 있거나 IPC가 연결되지 않으면 호출 전에 반환합니다. 그 외에는 ipc의 recv를 현재 객체 this의 {{proxy_name}}Isolated::recvMessage 콜백에 connect로 연결합니다. {{proxy_name}}Isolated::{{proxy_name}}Isolated()의 대입문은 ipc_를 대상으로 하고 우변에 std::move(ipc)를 사용합니다. {{proxy_name}}Isolated 생성자는 이 코드 지점에서 valid_에 true를 대입합니다.

IPAProxy::resolvePath는 먼저 execPaths_를 순서대로 확인하고 빈 디렉터리를 건너뛰며, 실행 권한이 있는 첫 번째 worker 경로를 반환합니다. 그다음 utils::libcameraBuildPath()가 비어 있지 않으면 해당 빌드 경로의 src/libcamera/proxy/worker를 확인하고, 비어 있으면 설치 디렉터리 IPA_PROXY_DIR을 확인합니다. 선택한 디렉터리에서 실행 권한이 있는 worker를 찾으면 그 경로를 반환하고, 찾지 못하면 빈 문자열을 반환합니다.

IPCPipeUnixSocket::sendSync는 입력 페이로드, 응답 저장 위치와 헤더의 쿠키로 call을 호출하고, 오류가 반환되면 그 값을 반환합니다. call은 쿠키와 응답 저장 위치, 완료 상태를 callData_에 삽입하려고 하며 삽입 성공 여부는 확인하지 않습니다. 메시지 전송에 실패하면 해당 반복자의 항목을 지우고 오류를 반환하며, 성공하면 2000ms 타이머를 시작하고 완료 상태가 될 때까지 현재 스레드의 이벤트를 처리하다가 시간이 끝나면 항목을 지우고 -ETIMEDOUT을 반환합니다. readyRead는 수신에 성공하고 헤더 크기 이상의 데이터에서 일치하는 쿠키를 찾으면 페이로드를 해당 응답 위치에 옮기고 완료로 표시하며, call은 완료 후 항목을 지우고 0을 반환하고 sendSync는 out이 있으면 응답으로 IPCMessage를 만들어 저장한 뒤 0을 반환합니다.

\brief Find a valid full path for a proxy worker for a given executable name
 * \param[in] file File name of proxy worker executable
 *
 * A proxy worker's executable could be found in either the global installation
 * directory, or in the paths specified by the environment variable
 * LIBCAMERA_IPA_PROXY_PATH. This function checks the global install directory
 * first, then LIBCAMERA_IPA_PROXY_PATH in order, and returns the full path to
 * the proxy worker executable that is specified by file. The proxy worker
 * executable shall have exec permission.
 *
 * \return The full path to the proxy worker executable, or an empty string if
 * no valid executable path
 */
std::string IPAProxy::resolvePath(const std::string &file) const
{
    std::string proxyFile = "/" + file;

    /* Try paths from the configuration first. */
    for (const auto &dir : execPaths_) {
        if (dir.empty())
            continue;

        std::string proxyPath = dir + proxyFile;
        if (!access(proxyPath.c_str(), X_OK))
            return proxyPath;
    }

    /*
     * When libcamera is used before it is installed, load proxy workers
     * from the same build directory as the libcamera directory itself.
     * This requires identifying the path of the libcamera.so, and
     * referencing a relative path for the proxy workers from that point.
     */
    std::string root = utils::libcameraBuildPath();
    if (!root.empty()) {
        std::string ipaProxyDir = root + "src/libcamera/proxy/worker";

        LOG(IPAProxy, Info)
            << "libcamera is not installed. Loading proxy workers from '"
            << ipaProxyDir << "'";

        std::string proxyPath = ipaProxyDir + proxyFile;
        if (!access(proxyPath.c_str(), X_OK))
            return proxyPath;

        return std::string();
    }

    /* Else try finding the exec target from the install directory. */
    std::string proxyPath = std::string(IPA_PROXY_DIR) + proxyFile;
    if (!access(proxyPath.c_str(), X_OK))
        return proxyPath;

    return std::string();
}

{
    IPCUnixSocket::Payload payload;
    int ret = socket_->receive(&payload);
    if (ret) {
        LOG(IPCPipe, Error) << "Receive message failed" << ret;
        return;
    }

    /* \todo Use span to avoid the double copy when callData is found. */
    if (payload.data.size() < sizeof(IPCMessage::Header)) {
        LOG(IPCPipe, Error) << "Not enough data received";
        return;

    auto callData = callData_.find(ipcMessage.header().cookie);
    if (callData != callData_.end()) {
