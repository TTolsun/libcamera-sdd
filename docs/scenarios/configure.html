캡처 전에 준비할 스트림 구성

Camera::configure()는 캡처를 시작하기 전에 캡처에 참여할 스트림 묶음과 각 스트림의 구성을 고르는 함수입니다. 호출자는 config에 참여시킬 스트림과 구성을 채워 지정하며, 이 구성은 generateConfiguration()으로 만들고 호출자가 CameraConfiguration::validate()로 조정합니다. 이 함수는 완전히 유효한 구성만 받아들입니다.

configure()를 호출하기 전에 호출자는 acquire()를 호출해 카메라의 배타 접근을 확보해야 합니다. 이 함수는 카메라가 Acquired 또는 Configured 상태일 때만 호출할 수 있으며, 호출자는 카메라 상태를 바꾸는 다른 함수와 이 호출을 동기화해야 합니다. 배타 접근을 확보하지 않으면 -EACCES 오류가 반환되고, 카메라가 구성할 수 있는 상태가 아니어도 -EACCES가 반환됩니다. 카메라가 시스템에서 연결 해제된 경우 configure()는 -ENODEV를 반환합니다.

구성 적용과 성공 상태를 확인할 위치

Camera::configure()는 먼저 d->isAccessAllowed(Private::CameraAcquired, Private::CameraConfigured)의 반환값이 0보다 작으면 그 값을 그대로 반환합니다. 이어서 for 루프에서 모든 cfg.setStream(nullptr)를 호출해 이전 Stream 연결을 비웁니다. 그다음 config->validate()가 CameraConfiguration::Valid가 아니면 LOG(Camera, Error)로 "Can't configure camera with invalid configuration"을 출력하고 -EINVAL을 반환합니다. 따라서 검증에 실패해도 Stream 연결 비우기는 이미 끝난 뒤입니다.

Camera::configure()는 검증을 통과하면 d->pipe_->invokeMethod(&PipelineHandler::configure, ConnectionTypeBlocking, this, config)로 파이프라인 핸들러의 configure를 호출합니다. 호출 결과 ret이 0이 아니면 return ret;으로 그 값을 그대로 반환하며, 이 경우 이후의 Stream 연결 갱신 코드는 실행되지 않습니다.

invokeMethod가 0을 반환한 뒤 루프의 cfg.stream()이 nullptr인 항목이 있으면 LOG(Camera, Fatal)로 "Pipeline handler failed to update stream configuration"을 출력하는 경로에 들어갑니다. API 문서는 반환 시 config의 StreamConfiguration 항목이 StreamConfiguration::stream()으로 조회되는 Stream과 연결된다고 설명하며, 코드는 이 연결이 빠진 항목을 Fatal 경로로 검사합니다. 문서상 Fatal은 메시지 출력 뒤 실행을 중단하므로 d->activeStreams_.clear()와 return -EINVAL;은 실행되지 않으며, 검사 순서상 앞선 항목은 이미 configuration_ 저장과 activeStreams_ 삽입이 끝난 상태입니다.

invokeMethod가 0을 반환하고 각 항목의 cfg.stream()이 모두 nullptr이 아니면, 루프 전에 d->activeStreams_.clear()로 목록을 비운 뒤 각 항목마다 stream->configuration_ = cfg;를 저장하고 d->activeStreams_.insert(stream);을 호출합니다. 루프가 끝나면 d->setState(Private::CameraConfigured);로 상태를 CameraConfigured로 바꾸고 return 0;으로 성공을 반환합니다.

int Camera::configure(CameraConfiguration *config)
{
    Private *const d = _d();

    int ret = d->isAccessAllowed(Private::CameraAcquired,
                     Private::CameraConfigured);
    if (ret < 0)
        return ret;

    for (auto &cfg : *config)
        cfg.setStream(nullptr);

    if (config->validate() != CameraConfiguration::Valid) {
        LOG(Camera, Error)
            << "Can't configure camera with invalid configuration";
        return -EINVAL;
    }

    std::ostringstream msg("configuring streams:", std::ios_base::ate);

    for (unsigned int index = 0; index < config->size(); ++index) {
        StreamConfiguration &cfg = config->at(index);
        msg << " (" << index << ") " << cfg.toString();
    }

    LOG(Camera, Info) << msg.str();

    ret = d->pipe_->invokeMethod(&PipelineHandler::configure,
                     ConnectionTypeBlocking, this, config);
    if (ret)
        return ret;

    d->activeStreams_.clear();
    for (const StreamConfiguration &cfg : *config) {
        Stream *stream = cfg.stream();
        if (!stream) {
            LOG(Camera, Fatal)
                << "Pipeline handler failed to update stream configuration";
            d->activeStreams_.clear();
            return -EINVAL;
        }

        stream->configuration_ = cfg;
        d->activeStreams_.insert(stream);
    }

    d->setState(Private::CameraConfigured);

    return 0;
}
