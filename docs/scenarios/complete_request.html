요청 완료를 알릴 책임과 접근 종료

파이프라인 핸들러는 CameraManager 스레드에서 completeBuffer를 호출해야 하며, 이 함수는 버퍼 완료를 알린 뒤 요청의 내부 버퍼 추적을 갱신합니다. 모든 버퍼가 완료되고 필요한 추가 작업을 마친 뒤 핸들러는 같은 스레드에서 completeRequest를 호출해 카메라에 요청 완료를 알려야 하며, 이 함수가 반환한 뒤에는 해당 요청에 접근해서는 안 됩니다. completeRequest의 함수 반환 시점과 별개로 요청은 앱에 제출 순서대로 반환됩니다. 공통 cancelRequest는 Request::Private::cancel이 정상 복귀한 뒤 직접 completeRequest를 호출하며, doCancelRequest의 버퍼 완료 알림 자체가 요청 완료를 보장하지는 않습니다.
