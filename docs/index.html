읽는 순서

카메라와 요청 모델에서는 클래스별 책임, 상태와 허용 호출, 요청 생성과 완료, 소유권과 재사용, 오류와 종료, 동시성과 실행 확인의 여섯 절을 읽을 수 있습니다.

Pipeline Handler와 IPA 관리와 구현 진입점에서 공통 구조를 살펴보고, IPU3 LSC와 상태 연결에서 추가된 알고리즘의 직접 상속과 필드 참조를 확인하세요.

IPU3 LSC의 설정과 프레임 처리에서는 초기 그리드와 크롭 설정, 첫 프레임 활성화, 색온도에 따른 파라미터 갱신 및 메타데이터 전달을 확인하세요. 본문과 상태 연결 그림을 함께 제공합니다.

설명과 근거

카메라의 핵심 계약은 코드와 대조한 설명을 소스 발췌 해시에 연결했습니다. LSC 구조 설명과 그림은 추출 facts에서 직접 생성합니다. Pipeline Handler와 IPA의 설명은 로컬 모델이 작성한 초안입니다. 그림의 관계는 호출 순서나 실행 스레드를 뜻하지 않습니다.

LSC 설정과 프레임 처리 설명도 소스 발췌 해시에 연결하며 Qwen을 호출하지 않고 생성합니다. 페이지의 모델 표시는 생성 설정에 등록된 모델이며, 각 페이지의 실제 생성 방식은 이 안내와 배포 기록에서 구분합니다.

소스 링크는 해당 분석 커밋의 파일과 줄을 가리킵니다. 관계 그림을 눌러 확대하거나 요소 이름을 검색할 수 있습니다.
