할당 전에 확인할 카메라 상태와 스트림

allocate()를 호출하기 전에 카메라는 Camera::configure()로 미리 구성되어 있고 정지해야 하며, 스트림은 활성 카메라 구성에 속해야 합니다. 카메라 상태가 버퍼를 할당할 수 없는 경우에는 -EACCES가 반환되고, stream이 카메라에 속하지 않거나 활성 카메라 구성의 일부가 아닌 경우에는 -EINVAL이 반환됩니다.

중복 할당과 내보내기 실패를 구분하기

try_emplace의 inserted가 false이면 FrameBufferAllocator::allocate()는 "Buffers already allocated for stream" 오류 로그를 남기고 -EBUSY를 반환합니다. camera_->exportFrameBuffers(stream, &it->second)가 반환한 값은 변수 ret에 저장됩니다. 따라서 exportFrameBuffers()는 함수이고 ret는 그 반환값을 담는 변수입니다. ret가 음수, 즉 ret < 0이면 allocate()는 buffers_.erase(it)를 실행해 it가 가리키는 buffers_ 항목을 제거합니다.

FrameBufferAllocator::allocate는 exportFrameBuffers 호출 결과인 ret를 음수 여부와 관계없이 그대로 반환합니다.

free의 스트림 조회와 반환값

stream을 찾지 못하면, 즉 iter가 buffers_.end()와 같으면 -EINVAL을 반환하고 buffers_의 항목을 제거하지 않습니다. 스트림을 찾은 경우에는 해당 항목을 buffers_.erase(iter)로 삭제한 뒤 0을 반환합니다.

int FrameBufferAllocator::allocate(Stream *stream)
{
    const auto &[it, inserted] = buffers_.try_emplace(stream);

    if (!inserted) {
        LOG(Allocator, Error) << "Buffers already allocated for stream";
        return -EBUSY;
    }

    int ret = camera_->exportFrameBuffers(stream, &it->second);
    if (ret == -EINVAL)
        LOG(Allocator, Error)
            << "Stream is not part of " << camera_->id()
            << " active configuration";

    if (ret < 0)
        buffers_.erase(it);

    return ret;
}

int FrameBufferAllocator::free(Stream *stream)
{
    auto iter = buffers_.find(stream);
    if (iter == buffers_.end())
        return -EINVAL;

    buffers_.erase(iter);

    return 0;
}
