지원 조건과 구성 제약을 확인하고 제품 도입 전에 검증할 범위를 정하세요.

이 문서의 용어: Pipeline Handler, FPS, 디베이어, bayer 외 1개
  • Pipeline Handler: 특정 하드웨어 플랫폼(IPU3, RKISP1 등)의 미디어 장치를 찾아 카메라를 만들고, 요청을 장치에 넣고 완료를 돌려주는 libcamera 구성 요소입니다. 플랫폼마다 하나씩 있습니다.
  • FPS: FPS 는 초당 프레임 수를 의미합니다.
  • 디베이어: bayer 원시 데이터에서 화소마다 빠진 색을 주변 화소로 보간해 RGB 영상을 만드는 처리입니다. 디모자이크라고도 합니다.
  • bayer: 센서의 화소마다 R·G·B 중 한 색만 기록하는 색 필터 배열입니다. 이 형식의 원시 데이터는 디베이어를 거쳐야 화소마다 RGB 값을 가집니다.
  • ISP (Image Signal Processor): 센서가 출력한 원시(bayer) 데이터를 화면에 쓸 수 있는 영상으로 바꾸는 처리 장치입니다. 블랙 레벨 보정, 렌즈 음영 보정, 화이트 밸런스, 디베이어 등을 수행합니다.

다른 용어는 용어집에서 찾을 수 있습니다.

성능 근거를 읽는 기준

Benchmark 클래스에서 skipBeforeMeasure_ 멤버 변수는 소스 코드에 명시된 바와 같이 30 으로 초기화되어 있으며, 이는 측정 시작 전 안정화를 위해 건너뛰어야 할 프레임 수를 세기 위한 용도로 사용됩니다.

문단 근거 1개
  • include/libcamera/internal/software_isp/benchmark.hL21 발췌 · 전체 소스 L21

Benchmark 클래스의 framesToMeasure_ 멤버 변수는 소스 코드에서 unsigned int 타입으로 선언되었으며 초기값은 30 으로 설정되어 있습니다. 이 값은 Benchmark 클래스 내부의 private 섹션에 정의된 '/ Skip 30 frames for things to stabilize then measure 30 frames /' 주석과 함께 사용되며, 이는 프레임 처리 시간을 측정하기 위해 안정화될 때까지 건너뛰어야 하는 프레임 수 (skipBeforeMeasure_) 와 실제로 측정해야 할 프레임 개수 (framesToMeasure_) 를 의미합니다. 따라서 이 값은 초당 프레임 수 (FPS) 가 아닌, 성능 측정을 위해 선택적으로 포함되거나 제외될 프레임의 총 개수를 세는 데 사용됩니다.

static inline int64_t timeDiff(timespec &after, timespec &before)
{
    return (after.tv_sec - before.tv_sec) * 1000000000LL +
           (int64_t)after.tv_nsec - (int64_t)before.tv_nsec;
}

/**
 * \brief Start measuring process time for a single frame
 *
 * Call this function before processing frame data to start measuring
 * the process time for a frame.
 */
void Benchmark::startFrame(void)
{
    measure_ = framesToMeasure_ > 0 &&
           encounteredFrames_ < skipBeforeMeasure_ + framesToMeasure_ &&
           ++encounteredFrames_ > skipBeforeMeasure_;

    if (measure_) {
        frameStartTime_ = {};
        clock_gettime(CLOCK_MONOTONIC_RAW, &frameStartTime_);
    }
}

/**
 * \brief Finish measuring process time for a single frame
 *
 * Call this function after processing frame data to finish measuring
 * the process time for a frame.
 *
 * This function will log frame processing time information after
 * Benchmark::kLastFrameToMeasure frames have been processed.
 */
void Benchmark::finishFrame(void)
{
    if (measure_) {
        timespec frameEndTime = {};
        clock_gettime(CLOCK_MONOTONIC_RAW, &frameEndTime);
        frameProcessTime_ += timeDiff(frameEndTime, frameStartTime_);
        if (encounteredFrames_ == skipBeforeMeasure_ + framesToMeasure_) {
            LOG(Benchmark, Info)
                << name_ << " processed " << framesToMeasure_
                << " frames in " << frameProcessTime_ / 1000 << "us, "
                << frameProcessTime_ / (1000 * framesToMeasure_)
                << " us/frame";
        }
    }
}
