Check IPA module selection, thread and process boundaries, and request/result interfaces against the implementation.

Terms on this page: IPA, IPC, tuning file, proxy, and 10 more
  • IPA (Image Processing Algorithms): a separate module (.so) holding the image-quality algorithms. It reads the statistics sent by the ISP and computes the ISP settings for the next frame. It is kept apart from libcamera itself so that vendors can ship it without publishing the source.
  • IPC (Inter-Process Communication): message exchange between separate processes. Unsigned IPA modules run in a separate process, so libcamera calls them over IPC.
  • Tuning file: a YAML file with per-sensor and per-platform algorithm parameters (correction tables, colour matrices and so on). The IPA reads it at start-up.
  • Proxy: a stand-in object that takes calls through the same interface instead of calling the IPA module directly, and forwards them to the IPA thread or a separate process. It is generated from the mojom definition at build time.
  • IPU3 (Intel Image Processing Unit 3): the camera ISP in some Intel laptop processors. libcamera has a Pipeline Handler and an IPA for it.
  • RKISP1 (Rockchip Image Signal Processor 1): the camera ISP in Rockchip SoCs, the NXP i.MX8MP and others. libcamera has a Pipeline Handler and an IPA for it.
  • mali-c55: the Arm Mali-C55 camera ISP. libcamera has a Pipeline Handler and an IPA for it.
  • Software ISP: the libcamera component that does ISP processing on the CPU or GPU for devices without a hardware ISP. The source calls it software_isp and softisp.
  • ISP (Image Signal Processor): the processing unit that turns the sensor's raw (bayer) data into a usable image. It performs black-level correction, lens shading correction, white balance, debayering and more.
  • Shader: a small program that runs on the GPU. The software ISP can perform debayering and colour correction in GPU shaders.
  • LSC (Lens Shading Correction): correction for lens shading, where the image edges are darker or tinted compared with the centre because of the lens. It multiplies the image by a correction table laid out as a grid.
  • Black level: the baseline value a sensor outputs even with no light at all. It is subtracted in the first stage of ISP processing.
  • UQ: an unsigned fixed-point format. UQ<m, n> represents a value with m integer bits and n fractional bits.
  • AWB (Auto White Balance): the algorithm that estimates the colour temperature of the light and sets per-channel R, G and B gains so that white looks white.

Module discovery and isolation conditions

IPAManager adds user-specified module paths first. If an uninstalled build path is found, it adds src/ipa beneath it, then checks the installed system module path. The comment explicitly gives user-specified paths priority.

Thread and process boundaries

The Threaded proxy template calls init() directly on the IPA, then moves the internal proxy to its worker thread. During start(), it starts the thread and invokes the internal start method with a blocking call.

Paragraph evidence · 1
  • utils/codegen/ipc/generators/libcamera_templates/module_ipa_proxy.cpp.tmplL48 excerpt · Full source L48

Ordinary synchronous methods call the IPA object directly. Asynchronous methods check running state and use ConnectionTypeQueued to dispatch to the internal proxy. Not every method therefore reaches the worker thread in the same way.

Paragraph evidence · 1
  • utils/codegen/ipc/generators/libcamera_templates/module_ipa_proxy.cpp.tmplL48 excerpt · Full source L48

The Isolated proxy resolves the worker path and constructs IPCPipeUnixSocket. Only a connected pipe allows it to connect reception and mark itself valid. Method inputs are serialized and sent through sendAsync() for asynchronous methods or sendSync() for the others.

Paragraph evidence · 1
  • utils/codegen/ipc/generators/libcamera_templates/module_ipa_proxy.cpp.tmplL130 excerpt · Full source L130

The actual resolvePath() implementation checks configured paths first. When a build path exists, it checks the worker beneath it and returns an empty string if missing there. It checks the installation path only without a build path, so use the actual branches rather than the older comment claiming installation-first search.

Frame input and result interfaces

The IPU3 input interface declares asynchronous request controls through queueRequest(frame, controls), parameter-buffer selection through computeParams(frame, bufferId), and frame timestamp, statistics buffer and sensor controls through processStats(). Its event interface delivers per-frame paramsComputed, metadata, and sensor and lens controls.

IPA objects and shutdown order

IPAModule::load() loads the IPA implementation factory from a shared object. An invalid module, failure to open the object or failure to resolve the factory symbol returns failure; an already-loaded module returns success. createInterface() calls the factory for a valid, loaded module and returns null if those prerequisites are unmet.

Paragraph evidence · 1
  • src/libcamera/ipa_module.cppL390 excerpt · Full source L390

The Threaded constructor returns early if module loading or interface creation fails. On success, it owns the IPA interface through unique_ptr, connects events, and marks the proxy valid.

The Threaded stop code returns if it is not running; otherwise it enters ProxyStopping. It calls the internal stop() with a blocking invocation, then performs exit() and wait() on the thread. It dispatches remaining InvokeMessage messages for this proxy on the current thread before entering ProxyStopped.

Creation and IPC failures

createIPA() returns null for a missing matching module or an invalid created proxy. An invalid signature first selects Isolated and must be distinguished from those failure stages.

Paragraph evidence · 1
  • include/libcamera/internal/ipa_manager.hL35 excerpt · Full source L35

IPAModule::load() detects dlopen() failure or failure to find the ipaCreate symbol. On a missing symbol, it closes and clears the handle before returning failure. createInterface() also checks module validity and loading state before invoking the factory.

Paragraph evidence · 1
  • src/libcamera/ipa_module.cppL390 excerpt · Full source L390

The Isolated constructor does not reach a valid state if the worker path is empty or IPC connection fails. Generated methods log IPC transmission errors; methods with return values cast the error to their return type.

Paragraph evidence · 1
  • utils/codegen/ipc/generators/libcamera_templates/module_ipa_proxy.cpp.tmplL130 excerpt · Full source L130

The call() used by sendSync() sends the message, starts a 2000ms timer, and processes events while waiting for a response. Expiration removes the pending entry and returns -ETIMEDOUT. A socket-send failure also removes the entry and returns the error, distinguishing communication failure from module-selection failure.

Lens shading correction in the software ISP shaders

After black-level correction, the packed shader applies LSC when APPLY_LSC is defined. It samples the LSC texture at textureOut, multiplies the value by 4.0, and applies it to RGB. The comment explains the scale as conversion from UQ to floating point. AWB and clamping, the color-correction matrix, contrast and gamma follow in that order.

Paragraph evidence · 1
  • src/libcamera/shaders/bayer_1x_packed.fragL237 excerpt · Full source L237

The unpacked shader also applies conditional LSC after black-level correction, but uses center.xy as the texture coordinates. Its 4.0 scale and subsequent AWB, color-correction, contrast and gamma order match the packed path.

Paragraph evidence · 1
  • src/libcamera/shaders/bayer_unpacked.fragL140 excerpt · Full source L140

The SoftISP interface declares init() with SharedFD arguments for statistics and parameters, and ccmEnabled and lscEnabled outputs. It has no separate LSC-buffer argument, so this declaration does not establish a dedicated LSC-buffer transfer contract.

Paragraph evidence · 1
  • include/libcamera/ipa/softisp.mojomL1 excerpt · Full source L1

SoftISP declares asynchronous per-frame request, parameter-computation and statistics-processing methods. The interface and shader source do not constitute validation of actual GPU execution or image correction.

IPAManager::IPAManager(const CameraManager &cm)
    : cm_(cm)
{
    const GlobalConfiguration &configuration = cm._d()->configuration();

#if HAVE_IPA_PUBKEY
    if (!pubKey_.isValid())
        LOG(IPAManager, Warning) << "Public key not valid";

    forceIsolation_ = configuration.option<bool>({ "ipa", "force_isolation" })
                       .value_or(false);
#endif

    unsigned int ipaCount = 0;

    /* User-specified paths take precedence. */
    const auto modulePaths =
        configuration.listOption({ "ipa", "module_paths" })
            .value_or(utils::defopt);
    for (const auto &dir : modulePaths) {
        if (dir.empty())
            continue;

        ipaCount += addDir(dir.c_str());
    }

    if (!modulePaths.empty() && !ipaCount)
        LOG(IPAManager, Warning) << "No IPA found in '"
                     << utils::join(modulePaths, ":")
                     << "'";

    /*
     * When libcamera is used before it is installed, load IPAs from the
     * same build directory as the libcamera library itself.
     */
    std::string root = utils::libcameraBuildPath();
    if (!root.empty()) {
        std::string ipaBuildPath = root + "src/ipa";
        constexpr int maxDepth = 2;

        LOG(IPAManager, Info)
            << "libcamera is not installed. Adding '"
            << ipaBuildPath << "' to the IPA search path";

        ipaCount += addDir(ipaBuildPath.c_str(), maxDepth);
    }

    /* Finally try to load IPAs from the installed system path. */
    ipaCount += addDir(IPA_MODULE_DIR);

    if (!ipaCount)
        LOG(IPAManager, Warning)
            << "No IPA found in '" IPA_MODULE_DIR "'";
}

bool IPAModule::match(const char *name, uint32_t minVersion,
              uint32_t maxVersion) const

template<typename T>
    std::unique_ptr<T> createIPA(const char *name, uint32_t minVersion,
                     uint32_t maxVersion)
    {
        IPAModule *m = module(name, minVersion, maxVersion);
        if (!m)
            return nullptr;

        auto proxy = [&]() -> std::unique_ptr<T> {
            if (isSignatureValid(m))
                return std::make_unique<typename T::Threaded>(m, cm_);
            else
                return std::make_unique<typename T::Isolated>(m, cm_);
        }();

        if (!proxy->isValid()) {
            LOG(IPAManager, Error) << "Failed to load proxy";
            return nullptr;
        }

        return proxy;
    }

bool IPAManager::isSignatureValid([[maybe_unused]] IPAModule *ipa) const
{
#if HAVE_IPA_PUBKEY
    if (forceIsolation_) {
        LOG(IPAManager, Debug)
            << "Isolation of IPA module " << ipa->path()
            << " forced through configuration";
        return false;
    }

    File file{ ipa->path() };
    if (!file.open(File::OpenModeFlag::ReadOnly))
        return false;

    std::span<uint8_t> data = file.map();
    if (data.empty())
        return false;

    bool valid = pubKey_.verify(data, ipa->signature());

    LOG(IPAManager, Debug)
        << "IPA module " << ipa->path() << " signature is "
        << (valid ? "valid" : "not valid");

    return valid;
#else
    return false;
#endif
}

\brief Find a valid full path for a proxy worker for a given executable name
 * \param[in] file File name of proxy worker executable
 *
 * A proxy worker's executable could be found in either the global installation
 * directory, or in the paths specified by the environment variable
 * LIBCAMERA_IPA_PROXY_PATH. This function checks the global install directory
 * first, then LIBCAMERA_IPA_PROXY_PATH in order, and returns the full path to
 * the proxy worker executable that is specified by file. The proxy worker
 * executable shall have exec permission.
 *
 * \return The full path to the proxy worker executable, or an empty string if
 * no valid executable path
 */
std::string IPAProxy::resolvePath(const std::string &file) const
{
    std::string proxyFile = "/" + file;

    /* Try paths from the configuration first. */
    for (const auto &dir : execPaths_) {
        if (dir.empty())
            continue;

        std::string proxyPath = dir + proxyFile;
        if (!access(proxyPath.c_str(), X_OK))
            return proxyPath;
    }

    /*
     * When libcamera is used before it is installed, load proxy workers
     * from the same build directory as the libcamera directory itself.
     * This requires identifying the path of the libcamera.so, and
     * referencing a relative path for the proxy workers from that point.
     */
    std::string root = utils::libcameraBuildPath();
    if (!root.empty()) {
        std::string ipaProxyDir = root + "src/libcamera/proxy/worker";

        LOG(IPAProxy, Info)
            << "libcamera is not installed. Loading proxy workers from '"
            << ipaProxyDir << "'";

        std::string proxyPath = ipaProxyDir + proxyFile;
        if (!access(proxyPath.c_str(), X_OK))
            return proxyPath;

        return std::string();
    }

    /* Else try finding the exec target from the install directory. */
    std::string proxyPath = std::string(IPA_PROXY_DIR) + proxyFile;
    if (!access(proxyPath.c_str(), X_OK))
        return proxyPath;

    return std::string();
}

void IPCPipeUnixSocket::readyRead()
{
    IPCUnixSocket::Payload payload;
    int ret = socket_->receive(&payload);
    if (ret) {
        LOG(IPCPipe, Error) << "Receive message failed" << ret;
        return;
    }

    /* \todo Use span to avoid the double copy when callData is found. */
    if (payload.data.size() < sizeof(IPCMessage::Header)) {
        LOG(IPCPipe, Error) << "Not enough data received";
        return;
    }

    IPCMessage ipcMessage(payload);

    auto callData = callData_.find(ipcMessage.header().cookie);
    if (callData != callData_.end()) {
        *callData->second.response = std::move(payload);
        callData->second.done = true;
        return;
    }

    /* Received unexpected data, this means it's a call from the IPA. */
    recv.emit(ipcMessage);
}

int IPCPipeUnixSocket::call(const IPCUnixSocket::Payload &message,
                IPCUnixSocket::Payload *response, uint32_t cookie)
{
    Timer timeout;
    int ret;

    const auto result = callData_.insert({ cookie, { response, false } });
    const auto &iter = result.first;

    ret = socket_->send(message);
    if (ret) {
        callData_.erase(iter);
        return ret;
    }

    /* \todo Make this less dangerous, see IPCPipe::sendSync() */
    timeout.start(2000ms);
    while (!iter->second.done) {
        if (!timeout.isRunning()) {
            LOG(IPCPipe, Error) << "Call timeout!";
            callData_.erase(iter);
            return -ETIMEDOUT;
        }

        Thread::current()->eventDispatcher()->processEvents();
    }

    callData_.erase(iter);

    return 0;
}

\brief Load the IPA implementation factory from the shared object
 *
 * The IPA module shared object implements an IPAInterface object to be used
 * by pipeline handlers. This function loads the factory function from the
 * shared object. Later, createInterface() can be called to instantiate the
 * IPAInterface.
 *
 * This function only needs to be called successfully once, after which
 * createInterface() can be called as many times as IPAInterface instances are
 * needed.
 *
 * Calling this function on an invalid module (as returned by isValid()) is
 * an error.
 *
 * \return True if load was successful, or already loaded, and false otherwise
 */
bool IPAModule::load()
{
    if (!valid_)
        return false;

    if (loaded_)
        return true;

    dlHandle_ = dlopen(libPath_.c_str(), RTLD_LAZY);
    if (!dlHandle_) {
        LOG(IPAModule, Error)
            << "Failed to open IPA module shared object: "
            << dlerror();
        return false;
    }

    void *symbol = dlsym(dlHandle_, "ipaCreate");
    if (!symbol) {
        LOG(IPAModule, Error)
            << "Failed to load ipaCreate() from IPA module shared object: "
            << dlerror();
        dlclose(dlHandle_);
        dlHandle_ = nullptr;
        return false;
    }

    ipaCreate_ = reinterpret_cast<IPAIntfFactory>(symbol);

    loaded_ = true;

    return true;
}
