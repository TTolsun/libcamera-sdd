When to start discovery and use the camera

CameraManager::start() starts the camera manager and enumerates all devices in the system. Once the start is confirmed, the user can list the cameras in the system and interact with them. This availability scope lasts until either the camera manager is stopped or the camera is unplugged from the system.

Manager thread initialization and failure handling

CameraManager::Private::start() first starts the thread with Thread::start(). Within the block that locks mutex_ with MutexLocker, cv_.wait waits until initialized_ becomes true, and then the value of status_ is copied into status. If status is less than 0, exit() and wait() are called in order and status is returned; otherwise, 0 is returned.

CameraManager::Private::run() first calls init() and stores the return value in ret. After locking mutex_, ret is written to status_, initialized_ is set to true, and the lock is released by calling mutex_.unlock(). After mutex_.unlock() completes, cv_.notify_one() is called; this notification is not included in the locked section. If ret is less than 0, cleanup() is called, and execution returns; otherwise, exec() is called and then cleanup() is called.

CameraManager::Private::init() creates enumerator_ using DeviceEnumerator::create(). If enumerator_ is absent or the result of enumerator_->enumerate() is not 0, -ENODEV is returned. Otherwise, createPipelineHandlers() is called, Private::createPipelineHandlers is connected to enumerator_->devicesAdded, and 0 is returned.

int CameraManager::Private::start()
{
    int status;

    /* Start the thread and wait for initialization to complete. */
    Thread::start();

    {
        MutexLocker locker(mutex_);
        cv_.wait(locker, [&]() LIBCAMERA_TSA_REQUIRES(mutex_) {
            return initialized_;
        });
        status = status_;
    }

    /* If a failure happened during initialization, stop the thread. */
    if (status < 0) {
        exit();
        wait();
        return status;
    }

    return 0;
}

void CameraManager::Private::run()
{
    LOG(Camera, Debug) << "Starting camera manager";

    int ret = init();

    mutex_.lock();
    status_ = ret;
    initialized_ = true;
    mutex_.unlock();
    cv_.notify_one();

    if (ret < 0) {
        cleanup();
        return;
    }

    /* Now start processing events and messages. */
    exec();

    cleanup();
}

int CameraManager::Private::init()
{
    CameraManager *const o = LIBCAMERA_O_PTR();
    ipaManager_ = std::make_unique<IPAManager>(*o);

    enumerator_ = DeviceEnumerator::create();
    if (!enumerator_ || enumerator_->enumerate())
        return -ENODEV;

    createPipelineHandlers();
    enumerator_->devicesAdded.connect(this, &Private::createPipelineHandlers);

    return 0;
}
