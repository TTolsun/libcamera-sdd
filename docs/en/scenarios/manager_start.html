When to start discovery and use the camera

CameraManager::start() starts the camera manager and enumerates all devices in the system. Once the start is confirmed, the user may list cameras in the system and interact with them. This availability scope remains in effect until either the camera manager is stopped or the camera is unplugged from the system.

Initialization and failure handling of the manager thread

CameraManager::Private::start() first starts the thread with Thread::start(). Inside the block where mutex_ is locked with MutexLocker, waiting is done with cv_.wait until initialized_ becomes true, and then the value of status_ is copied into status. If status is less than 0, exit() and wait() are called in order and then status is returned; otherwise, 0 is returned.

CameraManager::Private::run() first calls init() and stores the return value in ret. After locking mutex_, the function writes ret to status_, sets initialized_ to true, and then releases the lock with mutex_.unlock(). After mutex_.unlock() completes, the function calls cv_.notify_one(); this notification is not included in the locked section. If ret is less than 0, the function calls cleanup() and returns; otherwise, the function calls exec() and then calls cleanup().

CameraManager::Private::init() creates enumerator_ from DeviceEnumerator::create(). If enumerator_ is absent or the result of enumerator_->enumerate() is non-zero, -ENODEV is returned. Otherwise, createPipelineHandlers() is called, Private::createPipelineHandlers is connected to enumerator_->devicesAdded, and 0 is then returned.

int CameraManager::Private::start()
{
    int status;

    /* Start the thread and wait for initialization to complete. */
    Thread::start();

    {
        MutexLocker locker(mutex_);
        cv_.wait(locker, [&]() LIBCAMERA_TSA_REQUIRES(mutex_) {
            return initialized_;
        });
        status = status_;
    }

    /* If a failure happened during initialization, stop the thread. */
    if (status < 0) {
        exit();
        wait();
        return status;
    }

    return 0;
}

void CameraManager::Private::run()
{
    LOG(Camera, Debug) << "Starting camera manager";

    int ret = init();

    mutex_.lock();
    status_ = ret;
    initialized_ = true;
    mutex_.unlock();
    cv_.notify_one();

    if (ret < 0) {
        cleanup();
        return;
    }

    /* Now start processing events and messages. */
    exec();

    cleanup();
}

int CameraManager::Private::init()
{
    CameraManager *const o = LIBCAMERA_O_PTR();
    ipaManager_ = std::make_unique<IPAManager>(*o);

    enumerator_ = DeviceEnumerator::create();
    if (!enumerator_ || enumerator_->enumerate())
        return -ENODEV;

    createPipelineHandlers();
    enumerator_->devicesAdded.connect(this, &Private::createPipelineHandlers);

    return 0;
}
