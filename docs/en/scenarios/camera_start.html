Starting a capture session to submit requests to

Camera::start() starts a camera capture session. A list of controls may optionally be passed. The passed controls are applied before the camera is started. After the camera starts, the application may queue requests to the camera for processing, and processed requests are returned to the application. The capture session continues until the capture session is terminated by stop().

start() may be called only in the Configured state defined in camera_operation. The caller must synchronize start() with other functions that affect the camera state. If the camera has been disconnected from the system, the return value is -ENODEV; if the camera is not in a state where it can start, the return value is -EACCES.

Reflecting start control values and pipeline results

If controls exists, Camera::start preprocesses the copy copy made with ControlList copy(*controls); using patchControlList(copy), and passes this copy to invokeMethod. If controls is nullptr, it passes nullptr without copying or preprocessing. Both branches call PipelineHandler::start through invokeMethod with the ConnectionTypeBlocking connection type. The PipelineHandler::start documentation states that this function is called from the CameraManager thread, and describes the intended caller as the Camera class.

In Camera::start, if ret is not 0, ret is returned as is according to if (ret) return ret;, and d->setState(Private::CameraRunning) is not reached. If ret is 0, d->setState(Private::CameraRunning) is called to update the state to CameraRunning, and then execution reaches return 0;.

ASSERT(d->requestSequence_ == 0); runs after the isAccessAllowed check block and before the controls branch. If the check expression is false, ASSERT logs a Fatal-level error message and aborts program execution, unlike a path that returns an error code, such as ret. If NDEBUG is defined before log.h is included, ASSERT() generates no code.

int Camera::start(const ControlList *controls)
{
    Private *const d = _d();

    int ret = d->isAccessAllowed(Private::CameraConfigured);
    if (ret < 0)
        return ret;

    LOG(Camera, Debug) << "Starting capture";

    ASSERT(d->requestSequence_ == 0);

    if (controls) {
        ControlList copy(*controls);
        patchControlList(copy);
        ret = d->pipe_->invokeMethod(&PipelineHandler::start,
                         ConnectionTypeBlocking, this, &copy);
    } else {
        ret = d->pipe_->invokeMethod(&PipelineHandler::start,
                         ConnectionTypeBlocking, this, nullptr);
    }

    if (ret)
        return ret;

    d->setState(Private::CameraRunning);

    return 0;
}
