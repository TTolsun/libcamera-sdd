Starting a capture session to submit requests to

Camera::start() starts a camera capture session, and may optionally be passed a list of controls. The passed controls are applied before the camera is started. After starting, the application can queue requests to the camera for processing, and processed requests are returned to the application. The capture session continues until it is terminated with stop().

start() may only be called in the Configured state defined in camera_operation. The caller shall synchronize start() with other functions that affect the camera state. If the camera has been disconnected from the system, it returns -ENODEV; if the camera is not in a state where it can be started, it returns -EACCES.

Reflecting start control values and pipeline results

If controls exists, Camera::start preprocesses the copy copy made with ControlList copy(*controls); using patchControlList(copy), and passes this copy to invokeMethod. If controls is nullptr, the function passes nullptr without copying or preprocessing. In both branches, the function calls PipelineHandler::start through invokeMethod with the ConnectionTypeBlocking connection type. The PipelineHandler::start documentation states that this function is called from the CameraManager thread, and that its intended caller is the Camera class.

In Camera::start, if ret is not 0, control returns ret unchanged according to if (ret) return ret; and does not reach d->setState(Private::CameraRunning); if ret is 0, control calls d->setState(Private::CameraRunning) to update the state to CameraRunning and then reaches return 0;.

ASSERT(d->requestSequence_ == 0); runs after the isAccessAllowed check block and before the controls branch. If the condition is false, ASSERT logs a Fatal-level error message and aborts program execution. This differs from a path that returns an error code, such as ret. If NDEBUG is defined before log.h is included, ASSERT() generates no code.

int Camera::start(const ControlList *controls)
{
    Private *const d = _d();

    int ret = d->isAccessAllowed(Private::CameraConfigured);
    if (ret < 0)
        return ret;

    LOG(Camera, Debug) << "Starting capture";

    ASSERT(d->requestSequence_ == 0);

    if (controls) {
        ControlList copy(*controls);
        patchControlList(copy);
        ret = d->pipe_->invokeMethod(&PipelineHandler::start,
                         ConnectionTypeBlocking, this, &copy);
    } else {
        ret = d->pipe_->invokeMethod(&PipelineHandler::start,
                         ConnectionTypeBlocking, this, nullptr);
    }

    if (ret)
        return ret;

    d->setState(Private::CameraRunning);

    return 0;
}
