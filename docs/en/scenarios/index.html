Scenario Behaviors and conditions to check Entry point
Camera discovery (CameraManager::start) Check the success or failure of manager startup, then use the enumerated cameras. CameraManager::start()
Stream configuration (Camera::configure) Before capture, a valid stream configuration is applied, and the Stream linked to failure conditions is checked. Camera::configure(CameraConfiguration *)
Capture start (Camera::start) Start the configured camera and check whether it is in a state where requests can be submitted after a successful start. Camera::start(const ControlList *)
Request submission (Camera::queueRequest) Submit valid requests to the started camera, and check completion notifications separately. Camera::queueRequest(Request *)
Request completion (PipelineHandler::completeRequest) Distinguish between buffer completion and request completion, and check the notifications that return in submission order and the responsibility for ending access. PipelineHandler::completeRequest(Request *)
Capture stop request (Camera::stop) Stop capture, and check the conditions under which cancellation of pending requests is complete and the configuration state returns. Camera::stop()
