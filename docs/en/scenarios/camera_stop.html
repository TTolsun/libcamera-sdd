The call that stops capture and its state preconditions

The call that stops capture and its state preconditions

Camera::stop() is a function that immediately stops capture and request processing for the camera. According to the documentation, all waiting requests are cancelled and completed synchronously in an error state. This function may be called in any camera state defined in camera_operation. However, the caller must synchronize stop() with other functions that affect the camera state.

If d->isRunning() is false, stop() does nothing and immediately returns through return 0;. The todo item in the code comment indicates that work remains so that calls to stop() outside the Running state use the state-machine path instead of this shortcut. If isRunning() is true, the code calls d->isAccessAllowed(Private::CameraRunning), and if that result is negative, stop() returns that value unchanged. isAccessAllowed returns -ENODEV if disconnected_ is true and allowDisconnected is false, and returns -EACCES if the current state differs from the requested state.

If both isRunning() and the access check pass, the state is set to CameraStopping with d->setState(Private::CameraStopping). Then PipelineHandler::stop is called via d->pipe_->invokeMethod(&PipelineHandler::stop, ConnectionTypeBlocking, this), and the check that no requests are pending is performed with ASSERT(!d->pipe_->hasPendingRequests(this)). ASSERT generates no code if NDEBUG is defined before log.h is included; if the condition is false, a Fatal message is logged and program execution is aborted. After the check completes, the state is set to CameraConfigured with d->setState(Private::CameraConfigured), and execution exits normally with return 0;.

The order for canceling waiting requests after device shutdown

According to the documentation comment, PipelineHandler::stop is called from the CameraManager thread. This function moves waitingRequests_ of camera->_d() into the local variable waitingRequests via swap, and then calls stopDevice(camera). According to the comment, waiting requests are moved first to prevent requests from being requeued by the completeRequest() call inside stopDevice(), and waiting requests are cancelled after the device is stopped to preserve their order.

The loop in stop takes requests one at a time from waitingRequests, calls Request::Private::cancel(), and then calls doQueueRequest(). cancel() calls doCancelRequest(), and this function cancels each pending buffer, emits the bufferCompleted signal, sets cancelled_ to true, and clears pending_, notifiers_, and timer_. doQueueRequest() adds the request to queuedRequests_ of camera->_d(), assigns the value of requestSequence_ to the request's sequence_, and then increments the counter by 1. If cancelled_ is true, the queuing function calls completeRequest() and returns without calling queueRequestDevice(). The queuing function calls queueRequestDevice() only when cancelled_ is false, and if that call returns a non-zero value, the queuing function calls cancelRequest().

According to the comment, the reason doQueueRequest() is used instead of cancelRequest() is to assign a sequence number to the request, temporarily add the request to queuedRequests_, and have the request completed correctly in completeRequest(). The two ASSERT statements after the loop check, according to the comment, that no waiting requests remain by queuedRequests_ and waitingRequests_. Finally, data->requestSequence_ is initialized to 0.

\brief Stop capture from camera
 *
 * This function stops capturing and processing requests immediately. All
 * pending requests are cancelled and complete synchronously in an error state.
 *
 * \context This function may be called in any camera state as defined in \ref
 * camera_operation, and shall be synchronized by the caller with other
 * functions that affect the camera state. If called when the camera isn't
 * running, it is a no-op.
 *
 * \return 0 on success or a negative error code otherwise
 * \retval -ENODEV The camera has been disconnected from the system
 * \retval -EACCES The camera is not running so can't be stopped
 */
int Camera::stop()
{
    Private *const d = _d();

    /*
     * \todo Make calling stop() when not in 'Running' part of the state
     * machine rather than take this shortcut
     */
    if (!d->isRunning())
        return 0;

    int ret = d->isAccessAllowed(Private::CameraRunning);
    if (ret < 0)
        return ret;

    LOG(Camera, Debug) << "Stopping capture";

    d->setState(Private::CameraStopping);

    d->pipe_->invokeMethod(&PipelineHandler::stop, ConnectionTypeBlocking,
                   this);

    ASSERT(!d->pipe_->hasPendingRequests(this));

    d->setState(Private::CameraConfigured);

    return 0;
}

int Camera::Private::isAccessAllowed(State state, bool allowDisconnected,
                     const char *from) const
{
    if (!allowDisconnected && disconnected_)
        return -ENODEV;

    State currentState = state_.load(std::memory_order_acquire);
    if (currentState == state)
        return 0;

    ASSERT(static_cast<unsigned int>(state) < std::size(camera_state_names));

    LOG(Camera, Error) << "Camera in " << camera_state_names[currentState]
               << " state trying " << from << "() requiring state "
               << camera_state_names[state];

    return -EACCES;
}

\brief Stop capturing from all running streams and cancel pending requests
 * \param[in] camera The camera to stop
 *
 * This function stops capturing and processing requests immediately. All
 * pending requests are cancelled and complete immediately in an error state.
 *
 * \context This function is called from the CameraManager thread.
 */
void PipelineHandler::stop(Camera *camera)
{
    /*
     * Take all waiting requests so that they are not requeued in response
     * to completeRequest() being called inside stopDevice(). Cancel them
     * after the device to keep them in order.
     */
    Camera::Private *data = camera->_d();
    std::queue<Request *> waitingRequests;
    waitingRequests.swap(data->waitingRequests_);

    /* Stop the pipeline handler and let the queued requests complete. */
    stopDevice(camera);

    /* Cancel and signal as complete all waiting requests. */
    while (!waitingRequests.empty()) {
        Request *request = waitingRequests.front();
        waitingRequests.pop();

        /*
         * Cancel all requests by marking them as cancelled and calling
         * doQueueRequest() instead of cancelRequest(). This ensures
         * that the requests get a sequence number and are temporarily
         * added to queuedRequests_ so they can be properly completed in
         * completeRequest().
         */
        request->_d()->cancel();
        doQueueRequest(request);
    }

    /* Make sure no requests are pending. */
    ASSERT(data->queuedRequests_.empty());
    ASSERT(data->waitingRequests_.empty());

    data->requestSequence_ = 0;
}

void PipelineHandler::doQueueRequest(Request *request)
{
    LIBCAMERA_TRACEPOINT(request_device_queue, request);

    Camera *camera = request->_d()->camera();
    Camera::Private *data = camera->_d();
    data->queuedRequests_.push_back(request);

    request->_d()->sequence_ = data->requestSequence_++;

    if (request->_d()->cancelled_) {
        completeRequest(request);
        return;
    }

    int ret = queueRequestDevice(camera, request);
    if (ret)
        cancelRequest(request);
}

void Request::Private::doCancelRequest()
{
    Request *request = _o<Request>();

    for (FrameBuffer *buffer : pending_) {
        buffer->_d()->cancel();
        camera_->bufferCompleted.emit(request, buffer);
    }

    cancelled_ = true;
    pending_.clear();
    notifiers_.clear();
    timer_.reset();
}

/**
 * \brief Cancel a queued request
 *
 * Mark the request and its associated buffers as cancelled and complete it.
 *
 * Set each pending buffer in error state and emit the buffer completion signal
 * before completing the Request.
 */
void Request::Private::cancel()
{
    LIBCAMERA_TRACEPOINT(request_cancel, this);

    Request *request = _o<Request>();
    ASSERT(request->status() == RequestPending);

    doCancelRequest();
}
