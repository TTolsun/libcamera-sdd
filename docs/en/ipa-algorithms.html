Terms in this document: IPA, software ISP, ISP, tuning file, and 5 others
  • IPA (Image Processing Algorithms): a separate module (.so) holding the image-quality algorithms. It reads the statistics sent by the ISP and computes the ISP settings for the next frame. It is kept apart from libcamera itself so that vendors can ship it without publishing the source.
  • Software ISP: the libcamera component that does ISP processing on the CPU or GPU for devices without a hardware ISP. The source calls it software_isp and softisp.
  • ISP (Image Signal Processor): the processing unit that turns the sensor's raw (bayer) data into a usable image. It performs black-level correction, lens shading correction, white balance, debayering and more.
  • Tuning file: a YAML file with per-sensor and per-platform algorithm parameters (correction tables, colour matrices and so on). The IPA reads it at start-up.
  • RKISP1 (Rockchip Image Signal Processor 1): the camera ISP in Rockchip SoCs, the NXP i.MX8MP and others. libcamera has a Pipeline Handler and an IPA for it.
  • mali-c55: the Arm Mali-C55 camera ISP. libcamera has a Pipeline Handler and an IPA for it.
  • Shader: a small program that runs on the GPU. The software ISP can perform debayering and colour correction in GPU shaders.
  • LSC (Lens Shading Correction): correction for lens shading, where the image edges are darker or tinted compared with the centre because of the lens. It multiplies the image by a correction table laid out as a grid.
  • IPU3 (Intel Image Processing Unit 3): the camera ISP in some Intel laptop processors. libcamera has a Pipeline Handler and an IPA for it.

Other terms are in the Glossary.

Uncalibrated tuning files

RKISP1 and Mali-C55 pass to configurationFile() a filename formed by appending .yaml to the sensor model name, along with the fallback name uncalibrated.yaml. IPAProxy::configurationFile() first searches for a configuration file using the IPA module name and the requested filename, and returns the path if it finds one. If it does not find one and the fallback name is empty, it logs an error and returns an empty string. If the fallback name is not empty, it searches for a file using that name and logs a warning.

Both uncalibrated.yaml list Agc, Awb, BlackLevelCorrection, and Ccm, and the RKISP1 file also lists GammaOutCorrection.

Software ISP input buffer texture format

createDMABufTexture2D() maps GL_RED and GL_LUMINANCE to DRM_FORMAT_R8, respectively. GL_RG maps to DRM_FORMAT_GR88, and GL_RGBA maps to DRM_FORMAT_ARGB8888. In the switch statement of createDMABufTexture2D(), the default branch logs unhandled GL format at error level and returns -ENODEV. This branch has no assignment to the dmabuf_import_failed_ flag.

In createDMABufTexture2D(), if the result of eglCreateImageKHR() is EGL_NO_IMAGE_KHR, eglCreateImageKHR fail is written to the debug log. Then true is assigned to eglImage.dmabuf_import_failed_, and -ENODEV is returned. createInputDMABufTexture2D() passes false as the last argument to createDMABufTexture2D(), and createOutputDMABufTexture2D() passes true.

createDMABufTexture2D() initializes ret to 0. On the path that did not return from an earlier error branch, if output is true, it calls attachTextureToFBO(eglImage) to attach the texture to the framebuffer and assigns the return value to ret. If output is false, ret retains its initial value of 0, and the function ultimately returns ret.

Lens shading correction in the software ISP shaders

The main() in both shaders first subtracts blacklevel from rgb and divides by 1.0 - blacklevel. If APPLY_LSC is defined, it then applies lens shading correction. The packing shader samples lsc_tex at textureOut coordinates, while the unpacking shader samples it at center.xy coordinates; each multiplies rgb by the sample's RGB values multiplied by 4.0. This scaling is used to convert UQ<2, 6> values to floating point.

The main() in both shaders then multiplies by the awb gain, clamps each channel between 0 and 1, and applies the ccm color correction matrix. It then clamps rgb between 0 and 1 again, applies apply_contrast to each channel, and raises each to the gamma power.

Execution check: The IPASoftIspInterface.init() declaration takes fdStats and fdParams as libcamera.SharedFD arguments and includes lscEnabled in its return value. This declaration does not specify a separate LSC buffer argument or an association between that buffer and lsc_tex.

std::string IPAProxy::configurationFile(const std::string &name,
                    const std::string &fallbackName) const
{
    /*
     * The IPA module name can be used as-is to build directory names as it
     * has been validated when loading the module.
     */
    const std::string ipaName = ipam_->info().name;
    std::string confPath = ipaConfigurationFile(ipaName, name, configPaths_);
    if (!confPath.empty()) {
        LOG(IPAProxy, Info) << "Using tuning file " << confPath;
        return confPath;
    }

    if (fallbackName.empty()) {
        LOG(IPAProxy, Error)
            << "Configuration file '" << name
            << "' not found for IPA module '" << ipaName << "'";
        return std::string();
    }

    confPath = ipaConfigurationFile(ipaName, fallbackName, configPaths_);
    LOG(IPAProxy, Warning)
        << "Configuration file '" << name
        << "' not found for IPA module '" << ipaName
        << "', falling back to '" << confPath << "'";

int eGL::createDMABufTexture2D(eGLImage &eglImage, int fd, bool output)
{
    EGLint drm_format;
    int ret = 0;

    assertThread();

    switch (eglImage.format_) {
    case GL_RED:
    case GL_LUMINANCE:
        drm_format = DRM_FORMAT_R8;
        break;
    case GL_RG:
        drm_format = DRM_FORMAT_GR88;
        break;
    case GL_RGBA:
        drm_format = DRM_FORMAT_ARGB8888;
        break;
    default:
        LOG(eGL, Error) << "unhandled GL format";
        return -ENODEV;
    }

    // clang-format off
    EGLint image_attrs[] = {
        EGL_WIDTH, (EGLint)eglImage.width_,
        EGL_HEIGHT, (EGLint)eglImage.height_,
        EGL_LINUX_DRM_FOURCC_EXT, drm_format,
        EGL_DMA_BUF_PLANE0_FD_EXT, fd,
        EGL_DMA_BUF_PLANE0_OFFSET_EXT, 0,
        EGL_DMA_BUF_PLANE0_PITCH_EXT, (EGLint)eglImage.stride_,
        EGL_DMA_BUF_PLANE0_MODIFIER_LO_EXT, 0,
        EGL_DMA_BUF_PLANE0_MODIFIER_HI_EXT, 0,
        EGL_NONE,
    };
    // clang-format on

    EGLImageKHR image = vtable_.eglCreateImageKHR(display_, EGL_NO_CONTEXT,
                              EGL_LINUX_DMA_BUF_EXT,
                              NULL, image_attrs);

    if (image == EGL_NO_IMAGE_KHR) {
        LOG(eGL, Debug) << "eglCreateImageKHR fail";
        eglImage.dmabuf_import_failed_ = true;
        return -ENODEV;
    }

    activateBindTexture(eglImage);

    // Generate texture with filter semantics
    vtable_.glEGLImageTargetTexture2DOES(GL_TEXTURE_2D, image);
    vtable_.eglDestroyImageKHR(display_, image);

    // Nearest filtering
    glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_MIN_FILTER, GL_NEAREST);
    glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_MAG_FILTER, GL_NEAREST);

    // Wrap to edge to avoid edge artifacts
    glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_WRAP_S, GL_CLAMP_TO_EDGE);
    glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_WRAP_T, GL_CLAMP_TO_EDGE);

    if (output)
        ret = attachTextureToFBO(eglImage);

    return ret;
}

         * texture2D(...) = original_float * 2^6 (quantization) * 1/2^8 (texture byte to float)
