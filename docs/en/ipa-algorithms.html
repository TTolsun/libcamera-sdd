Terms in this document: IPA, software ISP, ISP, tuning file, and 5 others
  • IPA (Image Processing Algorithms): A separate module (.so) that contains image quality algorithms. It reads the statistics sent by the ISP and calculates the ISP settings to use for the next frame. It is separated from the libcamera core so that manufacturers can provide it without publishing its source.
  • Software ISP: A libcamera component that performs ISP processing on the CPU or GPU in place of a hardware ISP on devices without one. In the source, it is named software_isp or softisp.
  • ISP (Image Signal Processor): A processing unit that converts raw (Bayer) data output by the sensor into an image that can be displayed on screen. It performs operations such as black level correction, lens shading correction, white balance, and debayering.
  • Tuning file: A YAML file containing sensor- and platform-specific algorithm parameters (calibration tables, color matrices, etc.). IPA reads it when it starts.
  • RKISP1 (Rockchip Image Signal Processor 1): A camera ISP included in Rockchip SoCs, the NXP i.MX8MP, and others. libcamera has a Pipeline Handler and an IPA for this device.
  • mali-c55: Arm Mali-C55 camera ISP. libcamera has a Pipeline Handler and an IPA for this device.
  • Shader: A small program that runs on the GPU. A software ISP may perform debayering and color correction with GPU shaders.
  • LSC (Lens Shading Correction): Processing that corrects lens shading, the phenomenon in which the edges of an image are darker than the center or colors are distorted due to lens characteristics. It is applied by multiplying by a correction table that divides the image into a grid.
  • IPU3 (Intel Image Processing Unit 3): A camera ISP included in some Intel laptop processors. libcamera has a Pipeline Handler and an IPA for this device.

Other terms can be found in Glossary.

Tuning file before calibration

RKISP1 and Mali-C55 pass the file name made by appending .yaml to the sensor model name, and the fallback name uncalibrated.yaml, to configurationFile(). IPAProxy::configurationFile() first searches for the configuration file using the IPA module name and the requested file name, and if the search finds a path, IPAProxy::configurationFile() returns that path. If the search does not find a file and the fallback name is empty, IPAProxy::configurationFile() logs an error and returns an empty string. If the fallback name is not empty, IPAProxy::configurationFile() searches for a file with that name and logs a warning.

Both uncalibrated.yaml files list Agc, Awb, BlackLevelCorrection, and Ccm, and the RKISP1 file also lists GammaOutCorrection.

Texture format of the software ISP input buffer

createDMABufTexture2D() maps GL_RED and GL_LUMINANCE each to DRM_FORMAT_R8. GL_RG maps to DRM_FORMAT_GR88, and GL_RGBA maps to DRM_FORMAT_ARGB8888. In the switch statement of createDMABufTexture2D(), the default branch logs unhandled GL format at error level and returns -ENODEV. This branch does not assign the dmabuf_import_failed_ flag.

In createDMABufTexture2D(), if the result of eglCreateImageKHR() is EGL_NO_IMAGE_KHR, it records eglCreateImageKHR fail in the debug log. It then assigns true to eglImage.dmabuf_import_failed_ and returns -ENODEV. createInputDMABufTexture2D() passes false as the last argument of createDMABufTexture2D(), and createOutputDMABufTexture2D() passes true in the same position.

createDMABufTexture2D() initializes ret to 0. On a path that did not return in an earlier error branch, if output is true, attachTextureToFBO(eglImage) is called to attach the texture to the framebuffer, and its return value is assigned to ret. If output is false, ret keeps its initial value of 0. The function ultimately returns ret.

Lens shading correction in the software ISP shader

In both shaders, main() first subtracts blacklevel from rgb and divides the result by 1.0 - blacklevel. If APPLY_LSC is defined, the shaders then apply lens shading correction. The packing shader samples lsc_tex at textureOut coordinates, and the unpacking shader samples at center.xy coordinates. Each shader multiplies the RGB value of its sample by 4.0 and multiplies rgb by the resulting value. This multiplier is used to convert UQ<2, 6> values to floating point.

In both shaders, main() then multiplies by the awb gain, clamps each channel to the 0-to-1 range, and applies the ccm color correction matrix. Next, it clamps rgb to the 0-to-1 range again, applies apply_contrast to each channel, and then applies the gamma power.

Run verification item: the declaration of IPASoftIspInterface.init() takes fdStats and fdParams as libcamera.SharedFD arguments, and its return value includes lscEnabled. This declaration does not specify a separate LSC buffer argument or the connection between that buffer and lsc_tex.

std::string IPAProxy::configurationFile(const std::string &name,
                    const std::string &fallbackName) const
{
    /*
     * The IPA module name can be used as-is to build directory names as it
     * has been validated when loading the module.
     */
    const std::string ipaName = ipam_->info().name;
    std::string confPath = ipaConfigurationFile(ipaName, name, configPaths_);
    if (!confPath.empty()) {
        LOG(IPAProxy, Info) << "Using tuning file " << confPath;
        return confPath;
    }

    if (fallbackName.empty()) {
        LOG(IPAProxy, Error)
            << "Configuration file '" << name
            << "' not found for IPA module '" << ipaName << "'";
        return std::string();
    }

    confPath = ipaConfigurationFile(ipaName, fallbackName, configPaths_);
    LOG(IPAProxy, Warning)
        << "Configuration file '" << name
        << "' not found for IPA module '" << ipaName
        << "', falling back to '" << confPath << "'";

int eGL::createDMABufTexture2D(eGLImage &eglImage, int fd, bool output)
{
    EGLint drm_format;
    int ret = 0;

    assertThread();

    switch (eglImage.format_) {
    case GL_RED:
    case GL_LUMINANCE:
        drm_format = DRM_FORMAT_R8;
        break;
    case GL_RG:
        drm_format = DRM_FORMAT_GR88;
        break;
    case GL_RGBA:
        drm_format = DRM_FORMAT_ARGB8888;
        break;
    default:
        LOG(eGL, Error) << "unhandled GL format";
        return -ENODEV;
    }

    // clang-format off
    EGLint image_attrs[] = {
        EGL_WIDTH, (EGLint)eglImage.width_,
        EGL_HEIGHT, (EGLint)eglImage.height_,
        EGL_LINUX_DRM_FOURCC_EXT, drm_format,
        EGL_DMA_BUF_PLANE0_FD_EXT, fd,
        EGL_DMA_BUF_PLANE0_OFFSET_EXT, 0,
        EGL_DMA_BUF_PLANE0_PITCH_EXT, (EGLint)eglImage.stride_,
        EGL_DMA_BUF_PLANE0_MODIFIER_LO_EXT, 0,
        EGL_DMA_BUF_PLANE0_MODIFIER_HI_EXT, 0,
        EGL_NONE,
    };
    // clang-format on

    EGLImageKHR image = vtable_.eglCreateImageKHR(display_, EGL_NO_CONTEXT,
                              EGL_LINUX_DMA_BUF_EXT,
                              NULL, image_attrs);

    if (image == EGL_NO_IMAGE_KHR) {
        LOG(eGL, Debug) << "eglCreateImageKHR fail";
        eglImage.dmabuf_import_failed_ = true;
        return -ENODEV;
    }

    activateBindTexture(eglImage);

    // Generate texture with filter semantics
    vtable_.glEGLImageTargetTexture2DOES(GL_TEXTURE_2D, image);
    vtable_.eglDestroyImageKHR(display_, image);

    // Nearest filtering
    glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_MIN_FILTER, GL_NEAREST);
    glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_MAG_FILTER, GL_NEAREST);

    // Wrap to edge to avoid edge artifacts
    glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_WRAP_S, GL_CLAMP_TO_EDGE);
    glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_WRAP_T, GL_CLAMP_TO_EDGE);

    if (output)
        ret = attachTextureToFBO(eglImage);

    return ret;
}
