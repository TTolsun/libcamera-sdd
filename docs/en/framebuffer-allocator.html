Check duplicate allocation, buffer export failures, and the validity period of returned buffers.

Camera state and stream to check before allocation

Before calling allocate(), the camera must already be configured with Camera::configure() and must be stopped, and the stream must belong to the active camera configuration. If the camera state does not allow buffers to be allocated, -EACCES is returned. If stream does not belong to the camera or is not part of the active camera configuration, -EINVAL is returned.

Validity Period of References Returned by buffers

buffers() must be called only after buffer allocation for that stream with allocate() has succeeded. The buffers returned by buffers() are valid until free() is called for the same stream or the FrameBufferAllocator instance is destroyed.

Distinguishing duplicate allocation from export failure

If try_emplace's inserted is false, FrameBufferAllocator::allocate() logs the "Buffers already allocated for stream" error and returns -EBUSY. The value returned by camera_->exportFrameBuffers(stream, &it->second) is stored in the variable ret. Therefore, exportFrameBuffers() is a function, and ret is the variable that holds its return value. If ret is negative, that is, if ret < 0, allocate() runs buffers_.erase(it) and removes the entry in buffers_ that it points to.

FrameBufferAllocator::allocate returns ret, the result of the exportFrameBuffers call, unchanged, regardless of whether it is negative.

free Stream Lookup and Return Value

If stream is not found, that is, if iter is equal to buffers_.end(), return -EINVAL and do not remove the entry from buffers_. If the stream is found, erase that entry using buffers_.erase(iter) and then return 0.

int FrameBufferAllocator::allocate(Stream *stream)
{
    const auto &[it, inserted] = buffers_.try_emplace(stream);

    if (!inserted) {
        LOG(Allocator, Error) << "Buffers already allocated for stream";
        return -EBUSY;
    }

    int ret = camera_->exportFrameBuffers(stream, &it->second);
    if (ret == -EINVAL)
        LOG(Allocator, Error)
            << "Stream is not part of " << camera_->id()
            << " active configuration";

    if (ret < 0)
        buffers_.erase(it);

    return ret;
}

int FrameBufferAllocator::free(Stream *stream)
{
    auto iter = buffers_.find(stream);
    if (iter == buffers_.end())
        return -EINVAL;

    buffers_.erase(iter);

    return 0;
}
