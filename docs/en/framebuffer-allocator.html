Check for duplicate allocation, buffer export failure, and the validity period of returned buffers.

Document terms: EBUSY, errno
  • EBUSY: Calling FrameBufferAllocator::allocate() again on a stream that already has buffers allocated returns -EBUSY.
  • errno: the standard error numbers Linux functions use to report why they failed. libcamera functions return them as negative values. For example, -ENODEV means no device, -EACCES access denied, -EINVAL an invalid argument, -ENOMEM out of memory and -EXDEV a resource that belongs to another object.

Validity period of returned buffer references

buffers() shall only be called after successfully allocating buffers for a stream with allocate(). The buffers returned by buffers() are valid until free() is called for the same stream or FrameBufferAllocator is destroyed.

Distinguish between duplicate allocation and export failure

If inserted is false, returns -EBUSY. After storing the value returned by exportFrameBuffers() function in ret variable, if ret is less than 0, removes the corresponding entry from buffers_ map. After calling exportFrameBuffers, return ret is out of scope of both if statements and is always executed regardless of whether it's negative.

free's stream lookup and return values

If the stream is not found in FrameBufferAllocator::free (iter == buffers_.end()), -EINVAL is returned, and if the stream is found, the corresponding item is removed from buffers_ and 0 is returned.

int FrameBufferAllocator::allocate(Stream *stream)
{
    const auto &[it, inserted] = buffers_.try_emplace(stream);

    if (!inserted) {
        LOG(Allocator, Error) << "Buffers already allocated for stream";
        return -EBUSY;
    }

    int ret = camera_->exportFrameBuffers(stream, &it->second);
    if (ret == -EINVAL)
        LOG(Allocator, Error)
            << "Stream is not part of " << camera_->id()
            << " active configuration";

    if (ret < 0)
        buffers_.erase(it);

    return ret;
}

int FrameBufferAllocator::free(Stream *stream)
{
    auto iter = buffers_.find(stream);
    if (iter == buffers_.end())
        return -EINVAL;

    buffers_.erase(iter);

    return 0;
}
