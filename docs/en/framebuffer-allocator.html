Validity Period of References Returned by buffers

Before calling buffers(), buffers must be successfully allocated for the stream using allocate(). The buffers returned by buffers() remain valid until free() is called for the same stream or the FrameBufferAllocator instance is destroyed.

Distinguishing duplicate allocation from export failure

In FrameBufferAllocator::allocate, if inserted of try_emplace is false, an error is logged and -EBUSY is returned. FrameBufferAllocator::allocate() stores the return value of exportFrameBuffers() in the variable ret, and if ret is negative, removes the corresponding entry from buffers_ using erase. After the call to exportFrameBuffers, FrameBufferAllocator::allocate returns ret regardless of the sign of ret, outside the if statement that checks the sign of ret.

free Stream Lookup and Return Value

If FrameBufferAllocator::free cannot find the stream, it returns -EINVAL without removing the buffers_ entry. If it finds the stream, it removes the corresponding buffers_ entry and returns 0.

int FrameBufferAllocator::allocate(Stream *stream)
{
    const auto &[it, inserted] = buffers_.try_emplace(stream);

    if (!inserted) {
        LOG(Allocator, Error) << "Buffers already allocated for stream";
        return -EBUSY;
    }

    int ret = camera_->exportFrameBuffers(stream, &it->second);
    if (ret == -EINVAL)
        LOG(Allocator, Error)
            << "Stream is not part of " << camera_->id()
            << " active configuration";

    if (ret < 0)
        buffers_.erase(it);

    return ret;
}

int FrameBufferAllocator::free(Stream *stream)
{
    auto iter = buffers_.find(stream);
    if (iter == buffers_.end())
        return -EINVAL;

    buffers_.erase(iter);

    return 0;
}
