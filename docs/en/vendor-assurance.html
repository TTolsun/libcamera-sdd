Review support conditions and configuration constraints, then define what to validate before product adoption.

Terms used in this document: Pipeline Handler, FPS, Debayering, Bayer, and one other term.
  • Pipeline Handler: the libcamera component that finds a hardware platform's media devices (IPU3, RKISP1 and so on), creates cameras, queues requests to the devices and returns completions. There is one per platform.
  • FPS: FPS means frames per second.
  • Debayering: interpolating each pixel's missing colours from its neighbours to turn bayer raw data into an RGB image. Also called demosaicing.
  • bayer: a colour filter array where each sensor pixel records only one of R, G or B. Raw data in this format needs debayering before every pixel has RGB values.
  • ISP (Image Signal Processor): the processing unit that turns the sensor's raw (bayer) data into a usable image. It performs black-level correction, lens shading correction, white balance, debayering and more.

Other terms are in the Glossary.

How to interpret performance evidence

In the Benchmark class, the skipBeforeMeasure_ member variable is initialized to 30 as specified in the source code and is used to count the number of frames that must be skipped for stabilization before measurement begins.

Paragraph evidence · 1
  • include/libcamera/internal/software_isp/benchmark.hL21 excerpt · Full source L21

The framesToMeasure_ member variable of the Benchmark class is declared as unsigned int in the source code and initialized to 30. This value is used together with the '/ Skip 30 frames for things to stabilize then measure 30 frames /' comment defined in the private section of the Benchmark class, representing the number of frames to skip until stabilization (skipBeforeMeasure_) and the number of frames to actually measure (framesToMeasure_). Therefore, this value is used not for frames per second (FPS), but to count the total number of frames that are optionally included or excluded for performance measurement.

Paragraph evidence · 1
  • include/libcamera/internal/software_isp/benchmark.hL21 excerpt · Full source L21

The Benchmark constructor reads the skip and number values from the software_isp.measure setting; if that setting does not exist, it retains the default values defined as skipBeforeMeasure_ and framesToMeasure_, respectively.

Paragraph evidence · 1
  • src/libcamera/software_isp/benchmark.cppL32 excerpt · Full source L32

One condition for the measure_ variable to become true in the Benchmark::startFrame() function is that framesToMeasure_ > 0. Therefore, if framesToMeasure_ is 0, this condition evaluates to false, and measure_ must be false.

Paragraph evidence · 1
  • src/libcamera/software_isp/benchmark.cppL32 excerpt · Full source L32

The benchmark embedded in the DebayerCpu class measures only the time spent on statistics collection and Debayering, without measuring the time consumed by frame capture or output.

class Benchmark
{
public:
    Benchmark(const CameraManager &cm, const std::string &name);
    ~Benchmark();

    unsigned int framesToMeasure_ = 30;

Benchmark::Benchmark(const CameraManager &cm, const std::string &name)
    : name_(name)
{
    const GlobalConfiguration &configuration = cm._d()->configuration();

    skipBeforeMeasure_ = configuration.option<unsigned int>(
                        { "software_isp", "measure", "skip" })
                            .value_or(skipBeforeMeasure_);
    framesToMeasure_ = configuration.option<unsigned int>(
                        { "software_isp", "measure", "number" })
                            .value_or(framesToMeasure_);
}

Benchmark::~Benchmark()
{
}

static inline int64_t timeDiff(timespec &after, timespec &before)
{
    return (after.tv_sec - before.tv_sec) * 1000000000LL +
           (int64_t)after.tv_nsec - (int64_t)before.tv_nsec;
}

/**
 * \brief Start measuring process time for a single frame
 *
 * Call this function before processing frame data to start measuring
 * the process time for a frame.
 */
void Benchmark::startFrame(void)
{
    measure_ = framesToMeasure_ > 0 &&
           encounteredFrames_ < skipBeforeMeasure_ + framesToMeasure_ &&
           ++encounteredFrames_ > skipBeforeMeasure_;

    if (measure_) {
        frameStartTime_ = {};
        clock_gettime(CLOCK_MONOTONIC_RAW, &frameStartTime_);
    }
}

/**
 * \brief Finish measuring process time for a single frame
 *
 * Call this function after processing frame data to finish measuring
 * the process time for a frame.
 *
 * This function will log frame processing time information after
 * Benchmark::kLastFrameToMeasure frames have been processed.
 */
void Benchmark::finishFrame(void)
{
    if (measure_) {
        timespec frameEndTime = {};
        clock_gettime(CLOCK_MONOTONIC_RAW, &frameEndTime);
        frameProcessTime_ += timeDiff(frameEndTime, frameStartTime_);
        if (encounteredFrames_ == skipBeforeMeasure_ + framesToMeasure_) {
            LOG(Benchmark, Info)
                << name_ << " processed " << framesToMeasure_
                << " frames in " << frameProcessTime_ / 1000 << "us, "
                << frameProcessTime_ / (1000 * framesToMeasure_)
                << " us/frame";
        }
    }
}

} /* namespace libcamera */
