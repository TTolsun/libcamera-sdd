요청 큐잉

호출자는 카메라가 Running 상태일 때만 Camera::queueRequest()를 호출해야 합니다. 이 함수는 스레드 안전하며, 성공하면 0을 반환하고 그렇지 않으면 음수 오류 코드를 반환합니다. 카메라가 시스템에서 연결 해제된 경우 -ENODEV, 카메라가 실행 중이 아니어서 요청을 큐에 넣을 수 없는 경우 -EACCES, 요청이 해당 카메라에 속하지 않는 경우 -EXDEV를 반환합니다. 요청이 유효하지 않으면 -EINVAL, 요청을 처리할 버퍼 메모리가 없으면 -ENOMEM을 반환합니다.
