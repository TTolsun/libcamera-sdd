이 문서의 용어: errno, Pending, Pipeline Handler
  • errno: Linux 함수가 실패 원인을 알리는 표준 오류 번호입니다. libcamera 함수는 이 값을 음수로 돌려줍니다. 예를 들어 -ENODEV는 장치 없음, -EACCES는 접근 거부, -EINVAL은 잘못된 인자, -ENOMEM은 메모리 부족, -EXDEV는 다른 객체에 속한 자원을 뜻합니다.
  • Pending: 아직 완료 또는 취소로 바뀌지 않은 요청 상태입니다. 장치 처리가 시작됐다는 뜻은 아니며, 앞 요청이 이 상태이면 뒤 요청의 반환도 대기할 수 있습니다.
  • Pipeline Handler: 특정 하드웨어 플랫폼(IPU3, RKISP1 등)의 미디어 장치를 찾아 카메라를 만들고, 요청을 장치에 넣고 완료를 돌려주는 libcamera 구성 요소입니다. 플랫폼마다 하나씩 있습니다.

다른 용어는 용어집에서 찾을 수 있습니다.

CameraConfiguration::validate()의 Adjusted는 구성이 유효하도록 조정된 상태이며, 임의의 스트림에서 파라미터가 변경되거나 스트림 구성이 삭제될 수 있습니다. Adjusted를 받은 호출자는 구성을 주의 깊게 확인해야 합니다.

실행 확인 항목: 조사 계획에서는 Camera::configure의 config->validate() 결과를 CameraConfiguration::Valid와 비교하고, 결과가 다를 때 -EINVAL을 반환하는지 함께 기록할 수 있습니다.

기존 호출 스택에서 config의 실제 동적 타입과 실행되는 validate 구현을 기록하는 조사 계획입니다. 상태 확인과 검증을 통과한 경우 pipe_의 invokeMethod를 거쳐 호출되는 PipelineHandler::configure의 구체 구현과 반환값을 관찰하고, 반환값이 0이 아니면 Camera::configure가 그 값을 그대로 반환하는 분기를 기록합니다.
