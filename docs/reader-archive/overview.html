이 문서의 용어: IPA, Pipeline Handler
  • IPA (Image Processing Algorithms): 화질 알고리즘을 담은 별도 모듈(.so)입니다. ISP가 보낸 통계를 보고 다음 프레임에 쓸 ISP 설정값을 계산합니다. 제조사가 소스를 공개하지 않고 제공할 수 있도록 libcamera 본체와 분리되어 있습니다.
  • Pipeline Handler: 특정 하드웨어 플랫폼(IPU3, RKISP1 등)의 미디어 장치를 찾아 카메라를 만들고, 요청을 장치에 넣고 완료를 돌려주는 libcamera 구성 요소입니다. 플랫폼마다 하나씩 있습니다.

다른 용어는 용어집에서 찾을 수 있습니다.

캡처 세션의 상태와 자원

애플리케이션은 캡처를 준비할 때 acquire()로 카메라를 획득하고, configure()로 구성한 다음 start()로 시작합니다. 시작한 카메라는 정지할 때까지 요청을 처리할 수 있습니다. 애플리케이션이 Running 상태인 카메라의 사용을 완전히 끝낼 때는 stop()으로 정지하고, Stopping을 거쳐 Configured로 돌아온 후 release()로 해제합니다. 애플리케이션은 카메라를 해제하지 않은 동안 시작과 정지를 여러 번 반복하거나 카메라를 재구성할 수 있습니다.

Camera::start는 CameraConfigured 접근 검사 결과인 ret이 음수이면 그 값을 반환합니다. API 설명에 따르면 시작할 수 있는 상태가 아닐 때의 오류 코드는 -EACCES입니다. 접근 검사를 통과하면 PipelineHandler::start를 ConnectionTypeBlocking으로 호출하고, 그 결과인 ret이 0이 아니면 그대로 반환합니다. 결과가 0이면 상태를 CameraRunning으로 바꾼 뒤 0을 반환합니다.

 * \param[in] flags Indicate whether or not to reuse the buffers
 *

 * be reused and requeued without destruction. This function shall be called
 * prior to queueing the request to the camera, in lieu of constructing a new

 */
void Request::reuse(ReuseFlag flags)
{
    LIBCAMERA_TRACEPOINT(request_reuse, this);

    _d()->reset();

    if (flags & ReuseBuffers) {
        for (const auto &[stream, buffer] : bufferMap_) {
            buffer->_d()->setRequest(this);
            _d()->pending_.insert(buffer);
        }
    } else {
        bufferMap_.clear();
    }

    status_ = RequestPending;

    controls_.clear();
    _d()->metadata_.clear();
}

int Camera::start(const ControlList *controls)
{
    Private *const d = _d();

    int ret = d->isAccessAllowed(Private::CameraConfigured);
    if (ret < 0)
        return ret;

    LOG(Camera, Debug) << "Starting capture";

    ASSERT(d->requestSequence_ == 0);

    if (controls) {
        ControlList copy(*controls);
        patchControlList(copy);
        ret = d->pipe_->invokeMethod(&PipelineHandler::start,
                         ConnectionTypeBlocking, this, &copy);
    } else {
        ret = d->pipe_->invokeMethod(&PipelineHandler::start,
                         ConnectionTypeBlocking, this, nullptr);
    }

    if (ret)
        return ret;

    d->setState(Private::CameraRunning);

    return 0;
}
