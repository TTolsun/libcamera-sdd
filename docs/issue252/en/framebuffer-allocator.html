Camera state and streams to check before allocation

Before calling allocate(), the camera must be preconfigured with Camera::configure() and must be stopped, and the stream must belong to the active camera configuration. If the camera is in a state where buffers cannot be allocated, -EACCES is returned, and if stream does not belong to the camera or is not part of the active camera configuration, -EINVAL is returned.

Validity period of the reference returned by buffers

buffers() must only be called after buffer allocation for that stream has succeeded with allocate(). The buffers returned by buffers() are valid until free() is called for the same stream or the FrameBufferAllocator instance is destroyed.

Distinguishing duplicate allocation from export failure

If the inserted of try_emplace is false, FrameBufferAllocator::allocate() logs the "Buffers already allocated for stream" error and returns -EBUSY. The value returned by camera_->exportFrameBuffers(stream, &it->second) is stored in the variable ret. Therefore, exportFrameBuffers() is a function, and ret is the variable that holds that return value. If ret is negative, that is, ret < 0, allocate() runs buffers_.erase(it) to remove the buffers_ entry that it points to.

FrameBufferAllocator::allocate returns ret, the result of calling exportFrameBuffers, unchanged regardless of whether the value is negative.

Stream lookup and return value of free

If stream is not found, that is, if iter equals buffers_.end(), the function returns -EINVAL and does not remove the entry in buffers_. If the stream is found, the function deletes that entry with buffers_.erase(iter) and then returns 0.

int FrameBufferAllocator::allocate(Stream *stream)
{
    const auto &[it, inserted] = buffers_.try_emplace(stream);

    if (!inserted) {
        LOG(Allocator, Error) << "Buffers already allocated for stream";
        return -EBUSY;
    }

    int ret = camera_->exportFrameBuffers(stream, &it->second);
    if (ret == -EINVAL)
        LOG(Allocator, Error)
            << "Stream is not part of " << camera_->id()
            << " active configuration";

    if (ret < 0)
        buffers_.erase(it);

    return ret;
}

int FrameBufferAllocator::free(Stream *stream)
{
    auto iter = buffers_.find(stream);
    if (iter == buffers_.end())
        return -EINVAL;

    buffers_.erase(iter);

    return 0;
}
