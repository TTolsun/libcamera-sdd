Scenarios Behavior and conditions to check Entry point
Camera discovery (CameraManager::start) Confirm whether the manager start succeeded or failed before using the discovered cameras. CameraManager::start()
Stream configuration (Camera::configure) Apply a valid stream configuration before capture and check the Stream linked to the failure conditions. Camera::configure(CameraConfiguration *)
Capture start (Camera::start) Start the camera whose configuration is complete, and check whether, after the start succeeds, it can accept requests. Camera::start(const ControlList *)
Request submission (Camera::queueRequest) Submit valid requests to the started camera, and check completion notifications separately. Camera::queueRequest(Request *)
Request completion notification (PipelineHandler::completeRequest) Distinguish buffer completion from request completion, and check the notifications that return in submission order and the responsibility for ending access. PipelineHandler::completeRequest(Request *)
Request to end capture (Camera::stop) Stop capture and check the conditions for completing cancellation of pending requests and returning to the configuration state. Camera::stop()
